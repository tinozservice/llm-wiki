## TL;DR

Managed Windows Dedicated Server Exabytes: empat paket dari **Rp3.314.917/bln** (Xeon E3, 16 GB, 2×1 TB RAID1) hingga **Rp8.254.917/bln** (dual Xeon E5, 64 GB, 4×2 TB RAID1) — selisih ±Rp1,3–1,4 jt dari versi Linux karena sudah **termasuk Pro Managed Plan**. Dukungan **Microsoft SQL** + Windows Server 2008/2012/2014 (by request), akses RDP/SSH, server di NEX DC Tier-3.

## Key points

- Paket: Economy Rp3.314.917 (16 GB, 2×1 TB SATA); Value Rp4.634.917 (32 GB, 2×2 TB); Deluxe Rp6.614.917 (dual E5, 64 GB, 2×2 TB); Ultimate Rp8.254.917 (dual E5, 64 GB, 4×2 TB) — semuanya termasuk **Pro Managed Plan** + daily backup 14 hari + SSL gratis + 2 IP + 200 Mbps.
- Fitur khusus Windows: **Microsoft SQL** support, panel cPanel (opsional) atau Plesk, RDP untuk pengelolaan; Windows Server 2008/2012/2014 berdasarkan permintaan.
- Setup: klaim halaman "Instant" 4 jam vs FAQ "1 hari kerja" (untuk paket tertentu) vs Ultimate "7–14 hari kerja" — bervariasi per paket.
- Hardware: DELL, garansi penggantian 6 jam; kunjungan datacenter perlu notifikasi 24 jam (berbeda dari versi Linux yang melarang).
- T&C warisan: "Promosi 40% OFF ini berlaku sampai **31 Desember 2018**" — teks promo usang yang masih tampil di klip.
