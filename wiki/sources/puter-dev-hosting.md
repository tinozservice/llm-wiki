# Puter developer — Static Site Hosting

- **Sumber**: Puter developer — halaman produk *Hosting* (static site hosting)
- **Penulis**: Puter Technologies Inc.
- **URL**: <https://developer.puter.com/static-hosting/>
- **Tanggal publikasi**: tidak dicantumkan; klip dibuat 2026-10-07
- **Berkas mentah**: `raw/2026/oktober/07/puter developer. Hosting.md`

## TL;DR

Halaman produk hosting statis: drag & drop file → "Publish as Website" → live di subdomain `puter.site` gratis, **SSL gratis otomatis**, editor kode bawaan, dan perubahan langsung tayang tanpa rebuild.

## Key points

- Dikelola sebagai bagian dari cloud OS: antarmuka file/folder familiar, perubahan live instan, code editor bawaan.
- Diklaim: infrastruktur global (loading cepat), scaling ditangani, "Secure by Default" (SSL otomatis per situs).
- **Framework**: mendukung situs statis/SPA apa pun yang build ke file statis — React, Vue, Next.js, Nuxt, Svelte, Angular, Astro, **Flutter**, React Router (tutorial deploy per framework tersedia).
- Update konten: edit file langsung di Puter (editor bawaan) atau upload ulang — "Changes go live instantly. No rebuild or redeployment steps".

## Notable quotes

> "Drag, drop, and go live in seconds."

> "If it builds to static files, you can host it on Puter."
