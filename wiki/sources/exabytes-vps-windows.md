## TL;DR

VPS Windows Exabytes: **8 paket SSD** dari **Rp148.500/bln** (1 vCPU/2 GB/40 GB) hingga **Rp1.100.000/bln** (8 vCPU/8 GB/180 GB), semua **Windows Server 2022**, unlimited transfer, 100 Mbps, web console + **Remote Desktop (RDP)**, dan SSL gratis via Plesk.
