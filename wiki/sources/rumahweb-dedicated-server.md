## TL;DR

Dedicated server Rumahweb (datacenter Indonesia), harga mulai **Rp2.500.000** hingga **Rp13.499.000** per bulan. Pilihan dari Dual Intel E5 (24–28 core, 128 GB RAM, disk 2–4 TB) sampai AMD EPYC (16–64 core, RAM 64–256 GB) termasuk varian **GPU NVIDIA T4/L4**. Gratis lisensi cPanel; anti-DDoS; koneksi backend; managed services opsional.

## Key points

- Seri Intel: c2670-128g 2t Rp2,5 jt; c2670/c2680-128g Rp2,9 jt; c2690-128g 4t Rp4,2 jt (2×4 TB, RAID1).
- Seri bare-metal: t1/t2.small.x86 Rp4,699 jt (Xeon E-2278G/E-2388G, 8 core, 32 GB); a1.small.x86 Rp5,699 jt (EPYC 7302P 16 core/64 GB); m1/m2.small.x86 Rp5,609–6,119 jt (EPYC 7352/7402P 24 core); m1.medium.x86 Rp10,559 jt (7702P 64 core/128 GB); m1.large.x86 Rp13,199 jt (256 GB).
- **GPU**: a1.small.gpu.x86 Rp9,899 jt (EPYC 7302P + NVIDIA T4); a1.medium.gpu.x86 Rp13,499 jt (EPYC 9124 + NVIDIA L4).
- Fitur: akses root + console, brand server Dell/Supermicro/HP, anti-DDoS, backend network untuk clustering, control panel (restart/reinstall), managed services (tim >20 tahun), gratis lisensi cPanel.
