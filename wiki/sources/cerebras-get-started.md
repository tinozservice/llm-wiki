## TL;DR

Dashboard Cerebras Cloud: API belum aktif sampai metode pembayaran ditambahkan, dengan iming-iming **$5 kredit gratis**. Halaman menampilkan akses cepat ke dua model Shared Inference — **Qwen 3.8 27B** ($0.99/$1.49 per 1M) dan **OpenAI GPT OSS** ($0.35/$0.75) — plus daftar **Dedicated Endpoints** untuk model yang lebih besar.

## Key points

- Status klip: "API access isn't active yet" — perlu metode pembayaran untuk mulai; klaim **$5 free credits**.
- Saldo awal $0.00; metrik usage (token & API calls bulan lalu) masih 0.
- **Model cepat**: Qwen 3.8 27B (vision-language, coding, research, long-horizon agentic) dan OpenAI GPT OSS (coding real-time, dokumen, agentic research, on-premises teregulasi).
