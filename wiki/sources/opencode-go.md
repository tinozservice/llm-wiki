# Low cost coding models for everyone

- **Sumber**: OpenCode — halaman produk "Go" (harga dan batas langganan)
- **Penulis**: tidak dicantumkan
- **URL**: <https://opencode.ai/go>
- **Tanggal publikasi**: tidak dicantumkan; klip dibuat 2026-10-01
- **Berkas mentah**: `raw/opencode-go-Low cost coding models for everyone.md`

## TL;DR

OpenCode Go adalah langganan **$10/bulan** untuk akses model yang dikurasi untuk *agentic coding* — "generous limits and reliable access to the most capable open-source models". Tersedia juga **Go Plus $40/bulan** dengan limit lebih tinggi dan interupsi lebih sedikit. Batas diatur **per model**: estimasi request per 5 jam dan batas pemakaian bulanan, dengan nilai berbeda untuk Go dan Go Plus. Layanan bisa dipakai bersama agen apa pun, kelebihan pemakaian ditutup dengan *top up* kredit, dan langganan bisa dibatalkan kapan saja. Untuk waktu terbatas tersedia model gratis tanpa batas: **Space Bunny Free** (model anonim baru) dan **LongCat 2.5 Preview Free**.

## Key points

- **Go**: $10/bulan. **Go Plus**: $40/bulan — mencakup semua isi Go, limit lebih tinggi, interupsi lebih sedikit, untuk proyek besar.
- Empat penekanan halaman: harga langganan murah; limit lega dan akses andal; cocok untuk programmer sebanyak mungkin; lineup model terkurasi yang diuji untuk agentic coding.
- Alur pemakaian: buat akun → berlangganan → mulai coding.
- **Batas per model** (estimasi request / 5 jam dan batas pemakaian bulanan) tersedia untuk dua tingkat; tabel lengkap ada di [OpenCode](../entities/opencode.md).
- Model yang ditandai **New**: MiMo-V2.6-Pro, GPT 6 Luna, DeepSeek V4.1 Flash, MiMo-V2.6-Flash, Space Bunny Free, LongCat 2.5 Preview Free.
- **Model gratis tanpa batas (Limited Time)**: Space Bunny Free — disebut "a new anonymous model" — dan LongCat 2.5 Preview Free.
- **Muse Spark 1.3/1.2 Contributor** menautkan kebijakan penggunaan geografis ("Limited Regions") ke domain meta.com.
- FAQ halaman menyebut **Zen** ("Is Go the same as Zen?"); hubungan Go dengan Zen tidak dijelaskan di halaman ini.
- *Catatan rekonstruksi*: tabel asli memakai tab Go dan Go Plus; pada klip, nilai tiap sel tergabung sehingga di wiki dipisah dengan asumsi urutan (Go, Go Plus) — rasio antar nilai konsisten dengan pola itu. Definisi persis kolom "monthly usage" (mis. apakah batas nilai dolar) tidak dijelaskan halaman.
