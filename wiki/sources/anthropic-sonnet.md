## TL;DR

**Claude Sonnet 5.5** (rilis 28 Sep 2026): **$2/$10 per 1M token**, "upgrade jelas dari Sonnet 5 — 30% lebih cepat dan hingga 30% lebih murah untuk kebanyakan pekerjaan"; **hemat hingga 90% dengan prompt caching**, 50% dengan batch; **US-only inference 1,1×**. Model "speed + intelligence" untuk coding harian, agents well-scoped, desain, dan alur kerja enterprise; di CursorBench 4.0 mencapai 55,5% (kedua setelah Opus 5.5 per kutipan Cursor).

- **Harga**: $2/$10; cache read $0,10/M (0,05×) — dari [docs Pricing](anthropic-pricing.md).

- **Kemampuan**: coding siklus hidup penuh, long-horizon tasks dengan token lebih sedikit dari Sonnet 5, visual/design, dokumen.
- **Benchmark & pelanggan**: kutipan Slack, Box, Cursor, Epic, Unity, Hex, dll.; system card terpisah.
- Lineage: Sonnet 5 (Jun 2026), Sonnet 4.6 (Feb 2026), 4.5, 4.
