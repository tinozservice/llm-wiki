## Frequently Asked Questions

What is static site hosting?

Static site hosting is a way to publish websites that consist of fixed content, such as HTML, CSS, JavaScript, and media files. Unlike dynamic websites that require server-side processing, static sites are pre-built and served directly to visitors, making them faster, more secure, and easier to maintain.

What is Puter?

Puter is a cloud operating system that runs in your browser. It provides a familiar desktop environment where you can manage files, run applications, and host websites, all from the cloud. Think of it as your personal computer on the web, accessible from any device with an internet connection.

How do I host my website with Puter?

It's simple! Just drag and drop your website files into Puter, right-click the folder containing your site, and select "Publish as Website." You'll instantly get a free puter.site subdomain. Your site goes live in seconds.

Can I use any web frameworks?

Yes! Puter supports any static site or single-page application. Whether you're using React, Vue, Next.js, Nuxt, Svelte, Angular, Astro, or plain HTML. If it builds to static files, you can host it on Puter. Just build your project and upload the output folder.

How do I update the content of my website?

Updating your website is as easy as editing files on your computer. Simply modify your files directly in Puter using the built-in code editor, or upload new versions of your files. Changes go live instantly. No rebuild or redeployment steps required.
