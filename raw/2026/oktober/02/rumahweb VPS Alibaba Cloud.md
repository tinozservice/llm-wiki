## FAQ

#### Berapa lama VPS saya akan diaktifkan?

VPS Anda akan aktif dalam 1-1.5 jam setelah pembayaran diterima dan dikonfirmasikan (jika melalui bank transfer).

#### Apa saja batasan VPS Alibaba Cloud yang perlu saya tahu?

**Port 25**  
Alibaba Cloud memblokir port 25 baik masuk maupun keluar. Jika Anda menggunakan relayer email, Anda dapat menggunakan port 465.

**Bandwidth**  
Outbound bandwidth maksimal sebesar 30Mbps, sedangkan inboundnya sebesar 100Mbps.

**Snapshot**  
Anda hanya dapat membuat 3 snapshot untuk setiap instance / VPS.

#### Apakah Rumahweb akan membantu mengelola VPS yang disewa pelanggan?

Kami akan memastikan VPS up and running, sedangkan untuk aplikasi dan apapun yang berjalan di dalam VPS tersebut menjadi tanggungjawab pelanggan.

Jika Anda ingin menggunakan layanan managed VPS, kami persilahkan menggunakan layanan VPS Rumahweb di halaman: [https://www.rumahweb.com/vps-indonesia/](https://www.rumahweb.com/vps-indonesia/).

#### Apakah VPS Alibaba Cloud dapat diupgrade?

Ya. Anda dapat mengupgrade VPS Anda dengan CPU, RAM, dan Storage yang lebih tinggi. Yang tidak bisa dilakukan adalah melakukan downgrade.

#### Apakah saya bisa melakukan downgrade? Bagaimana caranya?

Anda TIDAK DAPAT mendowngrade VPS yang sudah dibeli. Jika Anda ingin mendowngrade maka yang bisa dilakukan adalah membeli VPS dengan spesifikasi lebih rendah lalu memindahkan datanya secara manual.

#### Di kolom "bandwidth" terdapat 2 ukuran yaitu x TB dan y Mbit/s. Apa maksudnya?

Satuan TB menyatakan batasan total traffic outbound maksimal VPS dalam 1 bulan, sedangkan satuan Mbit/s menyatakan satuan kecepatan transfer data yang diijinkan.

#### Apa yang terjadi jika VPS saya melebihi jumlah total traffic yang diperbolehkan?

VPS Anda akan berhenti terputus dari internet dan account Alibaba Cloud akan di suspend sampai vps yang melebihi penggunaan resource di-upgrade. Detail AUP VPS Alibaba Cloud dapat dilihat pada link berikut: [https://www.rumahweb.com/tentang/acceptable-use-policy-aup](https://www.rumahweb.com/tentang/acceptable-use-policy-aup).

#### Saya memesan VPS dengan cPanel/Plesk tapi mengapa belum terinstall?

Yang kami lakukan adalah mengaktifkan VPS dan mengaktifkan lisensi atas IP VPS Anda. Selanjutnya Anda dapat menginstall cPanel secara mandiri dengan mengikuti panduan instalasi cPanel.

Atau jika ingin kami bantu, silahkan kirim request melalui teknis@rumahweb.com dengan menyertakan password root dan IP Anda. Perlu diperhatikan bahwa kami hanya akan membantu install saja, konfigurasi akan menjadi tanggungjawab pelanggan sepenuhnya.

#### Mengapa saya tidak menerima password root di email aktivasi?

Kami meminimalkan pengiriman password melalui media email. Setelah VPS Anda aktif, Anda dapat mengeset password root melalui Control Panel VPS Alibaba Cloud.

#### Berapa persen-kah Jaminan uptime VPS Alibaba Cloud?

Alibaba Cloud memberikan jaminan 99.975% pada SLAnya. Jika terjadi downtime, kami akan meneruskan klaim Anda ke pihak Alibaba Cloud.

#### Apakah saya dapat me-reinstall VPS sendiri?

Ya. Anda dapat melakukan sendiri reinstall pada VPS melalui control panel Alibaba Cloud.

#### Apakah saya dapat menggunakan custom image sendiri?

Tidak, Anda hanya dapat menggunakan image-image yang disediakan oleh Alibaba Cloud.

#### Apakah VPS saya otomatis dibackup oleh Rumahweb?

Tidak. Anda harus melakukan backup sendiri dengan cara menggunakan fitur snapshot.

#### Apakah Rumahweb akan membantu migrasi data?

Tidak. Kami tidak dapat membantu Anda untuk migrasi data dari provider atau layanan lain meskipun dari Rumahweb.

#### Jika saya membatalkan layanan VPS, apakah saya akan mendapatkan refund?

Rumahweb tidak dapat me-refund atas pembatalan layanan VPS.
