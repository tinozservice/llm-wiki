## Features

- #1 Deploy
	### One-click deploy
	![](https://web-assets.nousresearch.com/portal/3db03d30299b7ffbcdf8f78c04cb60c904292bbd/assets/hermes-landing/cloud/cloud-feature-deploy.webp)
	#1 Deploy One-click deploy
	Pick a name, region and model. Your agent is online in seconds. No servers, no DevOps, no YAML.
- #2 Always on
	### Runs while you sleep
	![](https://web-assets.nousresearch.com/portal/3db03d30299b7ffbcdf8f78c04cb60c904292bbd/assets/hermes-landing/cloud/cloud-feature-always-on.webp)
	#2 Always on Runs while you sleep
	Your agent lives in the cloud 24/7 and scales to zero when idle. You only pay while it works.
- #3 Schedule
	### Focused automation
	![](https://web-assets.nousresearch.com/portal/3db03d30299b7ffbcdf8f78c04cb60c904292bbd/assets/hermes-landing/cloud/cloud-feature-schedule.webp)
	#3 Schedule Focused automation
	Natural-language scheduling for reports, backups, and briefings, running unattended through the gateway.
- #4 Connect
	### Every channel
	![](https://web-assets.nousresearch.com/portal/3db03d30299b7ffbcdf8f78c04cb60c904292bbd/assets/hermes-landing/cloud/cloud-feature-connect.webp)
	#4 Connect Every channel
	Telegram, Discord, Slack, Email, CLI. One cloud agent, one memory, every surface you already use.
- #5 Remember
	### Persistent memory
	![](https://web-assets.nousresearch.com/portal/3db03d30299b7ffbcdf8f78c04cb60c904292bbd/assets/hermes-landing/cloud/cloud-feature-remember.webp)
	#5 Remember Persistent memory
	Memory lives with the agent, not the device. It never forgets how it solved a problem, wherever you log in.
- #6 Scale
	### Isolated sandboxes
	![](https://web-assets.nousresearch.com/portal/3db03d30299b7ffbcdf8f78c04cb60c904292bbd/assets/hermes-landing/cloud/cloud-feature-scale.webp)
	#6 Scale Isolated sandboxes
	Every agent gets its own hardened container. Spin up parallel subagents without burning your context.
