## TL;DR

Panduan prompting lintas surface (Chat, Work, Codex): deskripsikan hasil yang dibutuhkan, tambahkan konteks yang mengubah jawaban, pasang boundary, siapkan hasil agar layak pakai, perbaiki lewat follow-up. Struktur bagian: Prompting overview · Describe the result · Add useful context (connected sources, plugins, personalisasi) · Set boundaries · Make the result ready · Improve with follow-up (steering & queuing) · Put the pieces together · Voice dictation · Contoh per surface (Chat/Work/Codex).

## Key points

- Prinsip sama untuk semua surface; perbedaan di ekspektasi hasil (jawaban vs deliverable vs kode).
- Boundary mencegah masalah nyata (mis. "stop sebelum mengirim", "gunakan hanya sumber ini").
- Contoh terstruktur per kategori (memahami topik, drafting, membandingkan opsi, rencana praktis; Work: efisiensi, file jadi, riset keputusan, koordinasi launch; Codex: menjelaskan codebase).
