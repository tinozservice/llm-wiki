# Exabytes — VPS Linux NVMe

- **Sumber**: Halaman produk VPS Linux NVMe Exabytes

## TL;DR

VPS NVMe Exabytes (self-managed) dengan dua keluarga paket: **Compute Optimised C1–C4** (Rp261.000–Rp1.985.000/bln) dan **Memory Optimised M1–M6** (Rp194.000–Rp2.980.000/bln), semua 100 Mbps, backup off-server mingguan, 1 snapshot, akses root penuh + konsol KVM. Klaim: **deploy otomatis 3 menit**, NVMe hingga **1 juta IOPS**, prosesor Intel Xeon Hexa-Core, ISO 27001:2013 + 9001:2015.

## Key points

- **Compute Optimised**: C1 Rp261.000 (4 GB/2 vCPU/100 GB, 4 TB transfer); C2 Rp493.000 (8/4/200 GB, 8 TB); C3 Rp958.000 (16/8/400 GB, 16 TB); C4 Rp1.985.000 (32/16/600 GB, 32 TB).
- **Memory Optimised**: M1 Rp194.000 (4 GB/1 vCPU/50 GB, 2 TB); M2 Rp328.000 (8/2/100 GB, 4 TB); M3 Rp659.000 (16/4/200 GB, 8 TB); M4 Rp1.123.000 (24/8/400 GB, 16 TB); M5 Rp1.322.000 (32/8/600 GB, 16 TB); M6 Rp2.980.000 (64/16/800 GB, 32 TB).
- (Harga = paket triennial; headline "mulai dari Rp50.000/bulan" tidak dirinci di klip.)
- Manajemen: **SolusVM** + konsol virtual KVM berbasis web + SSH; reload OS via panel; OS CentOS/Debian/Ubuntu; opsi cPanel (CentOS), Plesk Web Admin/Pro/Host.
- **Pro Management Plan Rp450.000/bln** — tim Exabytes mengelola VPS + instalasi.
- Add-on: **Acronis off-server backup**, **Imunify360**, layanan manajemen VPS.
- Backup: 2 titik mingguan off-server + restore kapan saja; snapshot 1; upgrade kapan saja.
- Kebijakan: 80% bandwidth untuk akses lokal Indonesia, 20% internasional; port 25 (implisit dari kebijakan umum VPS Exabytes).
- Tersertifikasi **ISO 27001:2013** (manajemen risiko data) & **9001:2015** (manajemen mutu).
