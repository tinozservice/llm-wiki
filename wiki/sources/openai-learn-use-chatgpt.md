## TL;DR

Panduan "cara memakai ChatGPT": pilih **Chat** (tanya/brainstorm), **Work** (outcome + hasil reviewable), atau **Codex** (software/teknis); tambahkan konteks (project, file, plugin); review hasil sebelum dipakai. Termasuk tabel perbandingan ChatGPT vs Codex di desktop dan fitur share snapshot Codex.

## Key points

- ChatGPT Work bisa: riset/analisis, pakai file & tools (projects, memories, Library, plugins), membuat file jadi (docs/slides/spreadsheet/PDF), visual interaktif (images, visualisasi, **Sites**), browser/computer use/appshots (desktop), jalankan kode & review, subagent & long-running work, scheduled tasks, skills, Voice.
- Cloud vs local work (desktop): cloud = isolated hosted (lanjut setelah app ditutup), local = file/apps/browser komputer.
- **Share snapshot Codex** (read-only, macOS): personal = siapa pun dengan link; workspace = anggota terautentikasi (atau invited); redaksi secret patterns; tidak bisa fork; revoke via Data controls.
- Review: verifikasi angka/nama/tanggal/kutipan; periksa file tiap bagian; pressure-test ("sumber apa yang dipakai?", "asumsi apa?", "apa yang tidak bisa diakses?").
