# Claude — Plans & pricing (konsumen & tim)

- **Sumber**: claude.com — halaman *Plans & pricing*

## TL;DR

Plan konsumen & tim Claude: **Free $0 · Pro $17/bln (tahunan, $200 di muka) atau $20 bulanan · Max mulai $100/bln (5× atau 20× pemakaian Pro)** — plus tab **Team & Enterprise** dan **API**. **Claude Code termasuk di Pro, Max, (dan Team/Enterprise)**; **Fable** tersedia lewat **usage credits** di Pro dan 50% weekly limits di Max. Konteks hingga **1M** tergantung model; **model training opt-out di semua plan**.

## Key points

- **Free**: chat web/desktop/mobile, web search, artifacts, memory, connectors, skills, eksekusi kode, proyek hingga 5; model Sonnet & Haiku.
- **Pro** ($17–20): Claude Code, Claude Science, Claude Design/Slides/Docs, Claude in Chrome & Microsoft 365/Outlook, Research, Projects; usage credits; model Opus ikut tersedia.
- **Max** (dari $100): 5× atau 20× lebih banyak pemakaian dari Pro, output limit lebih tinggi, early access, prioritas saat trafik tinggi; Fable = 50% weekly limits.
- **Keamanan & admin** (SSO, SCIM, audit logs, Compliance API, HIPAA-ready, kontrol retensi) terdaftar sebagai fitur tab Team/Enterprise — nilai sel di klip tidak tertangkap penuh.
- **Pembayaran**: kartu kredit; tagihan bulanan/tahunan (Pro); tim melalui seat.
- **Catatan klipping**: tabel fitur di klip kehilangan sebagian nilai sel (checkmark kosong) dan **tab API tidak tertangkap** — harga API resmi ada di [docs Pricing](anthropic-pricing.md).
