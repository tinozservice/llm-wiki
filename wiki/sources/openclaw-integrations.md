# OpenClaw — Integrations (29 kanal, 64 provider, 142 plugin)

- **Sumber**: openclaw.ai/integrations

## TL;DR

Katalog integrasi OpenClaw: **29 chat channels**, **64 model & media providers**, **142 official plugins**. Channel diinstal satu perintah/onboarding; provider memisahkan pilihan model, autentikasi, dan runtime eksekusi.

## Key points

- **Chat channels** (29): Discord, Feishu/Lark, Google Chat, iMessage (via `imsg`), IRC, LINE, Matrix, Mattermost, Microsoft Teams, Nextcloud Talk, Nostr, QQ Bot, Raft, Signal (signal-cli), Slack, SMS (Twilio), Synology Chat, Telegram, Tlon (Urbit), Twitch, Voice Call (Twilio/Telnyx/Plivo), WebChat, WeChat/Weixin, WhatsApp, Yuanbao, Zalo, Zalo ClawBot, Zalo Personal, ClickClack.
- **Model & media providers** (64; sorotan): Anthropic (Claude API + CLI), Google (Gemini API/OAuth), MiniMax (Coding Plan), Moonshot/Kimi, OpenAI (API + ChatGPT/Codex sign-in, eksekusi Codex native), Qwen, **SpaceXAI** (Grok OAuth/API; label dalam klip), Z.AI (GLM).
- **Tool bawaan & automasi**: web/browser, file & code, messaging actions, agents & sessions (subagent, ACP), generated media (image/video/music/TTS), Tool Search, automation 7 mekanisme (Scheduled Tasks, Heartbeat, Background Tasks, Task Flow, Hooks, Standing Orders, Webhooks), plugins & skills.
- **Gateway hosts & companion nodes**: macOS/Windows/Linux; **VPS & cloud** (Fly.io, Hetzner, GCP, Azure, exe.dev, EasyRunner, dll.); node iOS/Android (camera, screen, voice, Canvas), Windows Hub, macOS app.
- ClawHub = registry publik skill/plugin community.
