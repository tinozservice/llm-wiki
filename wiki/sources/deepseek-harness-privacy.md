# DeepSeek Harness — Privacy Policy

## TL;DR

Dua kategori layanan: **official model services** (akun DeepSeek; **session logs dikumpulkan** — input, upload, output, tool calls, konfigurasi plugin, data percakapan — dan dipakai untuk **melatih/memperbaiki teknologi termasuk model ML**) vs **custom model services** (tanpa register; input dikirim langsung ke model provider pilihan Anda; **DSH tidak menyimpan/memproses Input/Output di sisi server**). Controller: **Hangzhou DeepSeek Artificial Intelligence Co., Ltd.**

## Key points

- Akun DeepSeek **terpadu** (aplikasi, Open Platform, Harness) — akun dari satu layanan bisa login ke layanan lain.
- Data otomatis: device/network, log penggunaan, lokasi perkiraan (IP), cookies, payment order.
- Berbagi: service provider pihak ketiga (plugin/MCP/skills yang Anda pasang sendiri), grup korporat (storage, delivery, security, R&D, **foundation model training and optimization**), transaksi korporat, penegak hukum.
- Tidak ada profiling/automated decision; kontak `harness-privacy@deepseek.com`; hak privasi per yurisdiksi.
- Peringatan: jangan memberikan data pribadi sensitif ke layanan.

## Notable quotes

> "DeepSeek Harness does not store or process your Input and Output on the server side" (custom model services).
