# Claude Mythos (halaman produk)

- **Sumber**: anthropic.com — halaman model *Claude Mythos*
- **Penulis**: Anthropic
- **URL**: <https://www.anthropic.com/claude/mythos>

## TL;DR

Mythos = **model paling capable Anthropic untuk cybersecurity & biology research**, akses hanya untuk organisasi terverifikasi. **Mythos 5.1** (1 Sep 2026) bisa dipakai lewat **Cyber Verification Program** & **Life Sciences Verification Program**; **Claude Security kini berjalan di Mythos 5.1**. **Fable 5.1 adalah model dasar yang sama dengan safeguard** — safeguard Fable 5.1 kini bisa dipakai mengidentifikasi kerentanan kode dan intervensi biologi 85% lebih jarang. Penggunaan Mythos 5.1 mewajibkan **retensi data 30 hari** untuk safety monitoring.

## Key points

- **Riwayat**: Mythos 5 (9 Jun 2026, akses terbatas), sempat *unavailable* (12 Jun), **kontrol ekspor dicabut** (1 Jul 2026 — akses dipulihkan untuk organisasi AS), Project Glasswing diperluas (2 Jun, ~150 organisasi di 15+ negara).
- **Safeguard Fable 5.1**: memblokir penetrasi testing, generasi exploit, dan pemindaian kerentanan berbasis binary; pertanyaan dual-use biologi/kimia dirutekan ke model Opus; pengalaman fallback dijelaskan di support.
- **Pricing**: mulai $10 per 1 juta token input & $50 output (sama dengan Fable 5.1).
- Program verifikasi juga membuka kapabilitas cyber lanjutan di **Opus 5.5 & Sonnet 5.5** untuk tim keamanan ([pengumuman Cyber Verification Program](https://www.anthropic.com/news/cyber-verification-program)).

## Notable quotes
