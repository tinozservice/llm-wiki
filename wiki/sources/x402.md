# x402 (situs resmi)

- **Sumber**: x402.org — beranda
- **Penulis**: x402 Foundation
- **URL**: <https://x402.org/>
- **Tanggal publikasi**: halaman "last updated 2026-08-25"; klip dibuat 2026-10-08
- **Berkas mentah**: `raw/2026/oktober/08/x402.md`

## TL;DR

**x402** = standar terbuka & netral untuk **pembayaran internet-native**: satu baris middleware (`paymentMiddleware`) membuat endpoint membalas **HTTP 402 Payment Required** bila belum dibayar — klien (termasuk agen AI) membayar **instan dengan stablecoin** lalu retry, **tanpa akun/KYC/API key**. Angka 30 hari terakhir di situs: **75,41 juta transaksi · $24,24 juta volume · 94,06K pembeli · 22K penjual**. Protocol fee nol; blockchain-agnostic (EVM + Solana + lainnya); produksi & telah diaudit; di bawah payung **x402 Foundation** (pengumuman Linux Foundation).

## Key points

- **Cara kerja**: request → 402 (berisi opsi pembayaran) → agen bayar stablecoin → akses diberikan; tanpa manajemen API key.
- **Perbandingan "old way vs x402"**: lama = buat akun, KYC, beli kredit/langganan (prepaid), kelola key, pembayaran lambat; x402 = onboarding instan, bayar per request, tanpa key.
- **Properti**: zero protocol fees, zero wait ("money moves at the speed of the internet"), zero friction (tanpa data pribadi), zero centralization (siapa pun bisa build), zero restrictions (netral, tidak terikat jaringan tertentu).
- **Use case**: monetisasi API, **agentic commerce**, konten berbayar, apa pun yang lambat/mahal dengan metode tradisional; extensible ke metode pembayaran tradisional.
- **Status**: production-ready, jutaan transaksi, open-source & diaudit.
- Integrasi cepat lewat docs (contoh middleware per bahasa).
