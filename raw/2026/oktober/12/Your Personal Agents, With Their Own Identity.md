## Each agent has an identity

Set the tools and permissions it needs.

### Phone

Make calls, take calls, and send messages from its own number.

### Wallet

Make payments with permissions you control.

### Computer

Work in a dedicated workspace with the apps and tools it needs.

### Mail

Send and receive email from its own address.

## An agent with its own phone, email, wallet and computer

It takes the calls you forward to it, emails from its own address, pays with its own card, and keeps working after you log off.

## Frequently asked questions

How do I give an agent a job?

Set its responsibility and give it the context it needs. Review the work as it moves forward.

Can I work with more than one agent?

Yes. Create distinct agents for different responsibilities and keep their work in one workspace.

What does an agent identity include?

An agent can have its own email address, computer workspace, phone number, and wallet. You control what it can access and which actions need approval.

How do connectors and routines work?

Connect the services that hold the work, then define a routine for the steps you repeat.

When does an agent need my approval?

You set the review boundaries. The agent brings work back when a decision needs you.
