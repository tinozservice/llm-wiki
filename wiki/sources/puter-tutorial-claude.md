# Free, Unlimited Claude API (tutorial)

- **Sumber**: Puter developer — tutorial *Free, Unlimited Claude API*
- **Penulis**: Nariman Jelveh; Reynaldi Chernando; Puter Technologies Inc.
- **URL**: <https://developer.puter.com/tutorials/free-unlimited-claude-35-sonnet-api/>
- **Tanggal publikasi**: 2026-09-30; klip dibuat 2026-10-07
- **Berkas mentah**: `raw/2026/oktober/07/puter developer tutorial. Free, Unlimited Claude API.md`

## TL;DR

Tutorial mengakses lineup Claude lewat `puter.ai.chat()` tanpa API key Anthropic — termasuk pemakaian lanjutan: streaming, mode **fast**, dan model reasoning terkuat (**Fable 5.1**). Menegaskan perbedaan dengan kredit $5 satu kali milik Anthropic.

## Key points

- **Contoh**: Sonnet 5.5 (default), Haiku 4.5 & Opus 5.5 (ganti `model`), **Opus 5 fast** (`claude-opus-5-fast` — ~2,5× lebih cepat dari Opus 5 standar, harga 2×), Fable 5.1 untuk reasoning multi-langkah/agentik (contoh teka-teki logika).
- **Daftar 16 model Claude** yang tersedia: `claude-sonnet-5-5`, `claude-fable-5-1`, `claude-opus-5-5`, `claude-opus-5`, `claude-opus-5-fast`, `claude-fable-5`, `claude-sonnet-5`, `claude-opus-4.8-fast`, `claude-opus-4-8`, `claude-opus-4-7`, `claude-sonnet-4-6`, `claude-opus-4-6`, `claude-opus-4-5`, `claude-haiku-4-5`, `claude-sonnet-4-5`, `claude-sonnet-4`.
- Menegaskan lagi bahwa Puter.js cocok untuk Claude Code, Codex, **OpenCode**, Lovable, Replit.
- Pembanding: Anthropic memberi **$5 kredit satu kali** saat signup; setelah habis kembali ke model developer-pays. "Public GitHub repos that promise free API keys don't work."

## Notable quotes

> "There's no API key to manage, no credit to burn through, and each user covers their own usage through their Puter account."
