## Tanya Jawab (FAQ) web hosting

Pertanyaan dan jawaban seputar layanan web hosting.

### Apa itu web hosting dan fungsinya?

Web hosting adalah penggunaan server untuk menyimpan file dan database website sehingga bisa diakses di internet. Agar berfungsi dengan baik, website memerlukan paket hosting dengan resource yang cukup untuk menyimpan semua data.

Berikut jenis-jenis hosting yang umum ditemukan:

- **Shared hosting**. Satu server hosting untuk banyak website. Setiap user diberikan "jatah" ruang penyimpanan dan resource. Layanan ini merupakan opsi hemat bagi para blogger dan juga mereka yang hanya ingin sekadar menyalurkan hobi.
- **Hosting untuk WordPress**. Cara kerjanya hampir sama dengan shared hosting. Bedanya, managed hosting untuk WordPress menawarkan berbagai tool dan fitur untuk mengoptimalkan kecepatan dan performa website WordPress.
- **VPS hosting**. Anda bisa mendapatkan virtual server, resource, dan full root access untuk mengelola website. Artinya, Anda tidak perlu berbagi dengan user lain. VPS hosting sangat cocok untuk web developer profesional atau individu yang menguasai hal-hal teknis pembuatan website.
- **Cloud hosting**. Pilihan terbaik bagi Anda yang membutuhkan server powerful dan website dengan uptime tinggi, tapi murah. Cocok untuk freelancer dan web developer yang punya banyak klien.

Di Hostinger, web hosting sudah dilengkapi website builder berbasis AI, Instalasi WordPress Otomatis, hosting super ngebut dengan 99,9% uptime, dan harga super murah.

Anda bisa berlangganan paket shared web hosting terlebih dulu, kemudian upgrade ke [paket cloud hosting](https://www.hostinger.com/id/cloud-hosting) jika membutuhkan resource lebih atau pilih paket VPS jika Anda ingin kontrol dan resource yang lebih besar.

Bingung pilih paket? Lihat tutorial [cara pilih web hosting](https://hostinger.com/tutorials/how-to-choose-web-hosting-plan) untuk informasi lebih lanjut.

### Apa bedanya domain dan web hosting?

Web hosting adalah tempat untuk menyimpan website Anda, sehingga bisa diakses di internet. Sedangkan [nama domain](https://www.hostinger.com/id/domain-murah) adalah alamat website Anda, seperti hostinger.co.id. Kedua elemen ini sangat penting agar website berfungsi dengan baik.

Tanpa web hosting, Anda perlu mengubah komputer Anda menjadi website server. Hal ini tentu tidak mudah bagi pemula yang belum mengerti hal-hal teknis web development. Tanpa domain, orang harus memasukkan alamat IP (yang terdiri dari angka-angka) di browser untuk mencari website Anda. Pastinya tidak praktis dan sangat merepotkan.
