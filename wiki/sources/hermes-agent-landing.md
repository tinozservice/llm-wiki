## TL;DR

Landing resmi Hermes Agent: agen AI open-source & self-hosted dari **Nous Research** — memori persisten, skill yang dibuat sendiri, gateway pesan untuk Telegram/Discord/Slack/WhatsApp/Signal/Email/CLI ("one agent, one memory, every surface"). Enam kartu fitur: **Connect, Remember, Schedule, Delegate, Search, Experiment**. Desktop app macOS/Windows; terminal di Linux; **gratis di bawah lisensi MIT**.

## Key points

- **Connect** — hidup di banyak platform; **Remember** — belajar proyek, auto-generate skill; **Schedule** — penjadwalan bahasa alami untuk laporan/backup/briefing; **Delegate** — subagent terisolasi (percakapan, terminal, skrip Python RPC — "zero-context-cost pipelines"); **Search** — web search, browser automation, vision, image generation, TTS, multi-model reasoning; **Experiment** — sandbox lima backend: **local, Docker, SSH, Singularity, Modal** dengan container hardening & namespace isolation.
- **Nous Portal** (langganan berbayar opsional): **Free $0; Plus $20/bln; Super $100/bln; Ultra $200/bln** (masing-masing "10% bonus"); semua tier berbayar termasuk kredit bulanan untuk Hermes Agent, akses **200+ model**, dan built-in tool use.
