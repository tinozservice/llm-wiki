## Tanya Jawab (FAQ) harga hosting Hostinger

### Bagaimana cara mendaftarkan domain gratis dari paket hosting tahunan?

Untuk aktifkan domain gratis 12 bulan dari paket managed hosting untuk WordPress, cloud hosting, atau website builder tahunan, cukup login ke dashboard Anda, klik **Klaim domain**, cari domain yang diinginkan, lalu daftarkan.

### Bagaimana cara mengaktifkan SSL gratis?

Serahkan saja kepada kami. Sertifikat SSL gratis akan otomatis diaktifkan untuk amankan website Anda.

### Apakah saya bisa mengubah paket di kemudian hari?

Tentu, silakan upgrade paket Anda kapan saja seiring berubahnya kebutuhan Anda, tanpa perlu khawatir website down.

### Mengapa harga paket berbeda-beda?

Semua paket hosting kami sudah mencakup fitur keamanan dan performa untuk membuat website Anda online. Namun, setiap paket dirancang untuk kebutuhan berbeda. Misalnya, website portofolio pribadi tidak membutuhkan resource sebesar toko online atau dedicated online game server bagi developer. Dengan pilihan paket yang beragam, Anda hanya membayar fitur dan resource yang benar-benar Anda butuhkan.

### Apakah Hostinger menyediakan ecommerce hosting?

Tentu saja, di Hostinger tersedia berbagai paket ecommerce dengan fitur lengkap untuk membuat toko online dan mulai berjualan. Semua paket ecommerce kami sudah dilengkapi dengan manajemen inventaris, berbagai metode pembayaran, integrasi tool marketing, dan fitur reservasi. Bebas biaya transaksi, semua keuntungan Anda jadi milik Anda.

### Apakah saya bisa memindahkan website ke Hostinger?

Tentu. Proses migrasi website ke Hostinger gratis dan tidak memakan waktu lama. Anda bisa transfer website sebanyak yang Anda perlukan tanpa khawatir soal biaya, risiko kehilangan data, atau downtime.

### Bisakah saya transfer domain ke Hostinger?

Tentu saja! Cukup ikuti langkah-langkah yang tersedia untuk transfer domain ke Hostinger dengan mudah. Setelah itu, Anda bisa mengelola semua domain dan hosting di satu tempat.

### Mana yang paling cocok untuk web developer profesional? Web Hosting, Cloud Hosting, atau VPS Hosting?

Shared Hosting kami dirancang untuk memudahkan pemula dan pemilik bisnis kecil. Untuk web developer dan designer profesional, sebaiknya pilih VPS Hosting karena dilengkapi kontrol back-end, fleksibilitas, dan resource yang lebih besar. Untuk pilihan di antaranya, ada paket Cloud Hosting dengan resource lebih besar dari Shared Hosting, tapi kontrolnya lebih terbatas dari VPS Hosting.

### Apakah bisa buat website di WordPress dan hosting di Hostinger?

Tentu saja. Semua paket hosting kompatibel dengan WordPress. Paket managed hosting untuk WordPress sangat cocok untuk memaksimalkan performa website WordPress Anda. Sementara itu, paket hosting untuk WooCommerce kami cocok untuk Anda yang ingin buat website toko online.
