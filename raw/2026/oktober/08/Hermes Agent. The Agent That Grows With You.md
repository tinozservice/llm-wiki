## Features

#1 Connect

### Lives Everywhere

Telegram, Discord, Slack, WhatsApp, Signal, Email, CLI — and a growing list of platforms. One agent, one memory, every surface.

![](https://web-assets.nousresearch.com/nousnet-web/img/landing/feature-connect.3de66c3dcd817e73.webp)

#2 Remember

### Persistent Memory

It learns your projects, auto-generates skills, and never forgets how it solved a problem.

![](https://web-assets.nousresearch.com/nousnet-web/img/landing/feature-memory.f2a586f7a2ce02ce.webp)

#3 Schedule

### Focused Automation

Natural-language scheduling for reports, backups, and briefings — running unattended through the gateway, focused every time.

![](https://web-assets.nousresearch.com/nousnet-web/img/landing/feature-automation.ebc2f15d427478a2.webp)

#4 Delegate

### Tasks Multiplied

Isolated subagents with their own conversations, terminals, and Python RPC scripts for zero-context-cost pipelines.

![](https://web-assets.nousresearch.com/nousnet-web/img/landing/feature-delegate.e9bc31cd923cfa8c.webp)

#5 Search

### Browse the Web

Web search, browser automation, vision, image generation, text-to-speech, and multi-model reasoning.

#6 Experiment

### Isolated Sandboxing

Five backends — local, Docker, SSH, Singularity, Modal — with container hardening and namespace isolation.

![](https://web-assets.nousresearch.com/nousnet-web/img/landing/feature-sandbox.08ca50ee89c595b7.webp)
