## TL;DR

VPS NVMe Exabytes dengan **n8n included** — resource "memory optimised" untuk menjalankan otomatisasi workflow n8n secara self-hosted. Enam paket M1–M6 dengan harga identik seri NVMe lain: **Rp194.000–Rp2.980.000/bln** (triennial), 50–800 GB NVMe, 4–64 GB RAM, backup off-server mingguan.

## Key points

- Paket M1–M6: 4/8/16/24/32/64 GB RAM; 1/2/4/8/8/16 vCPU; 50/100/200/400/400/800 GB NVMe; transfer 2–32 TB; 100 Mbps; weekly off-server backup; 1 snapshot; uptime monitoring.
- Positioning per paket tidak dijabarkan di klip (hanya deskripsi umum "resource telah disesuaikan untuk n8n").
- Harga: Rp194.000 / 328.000 / 659.000 / 1.123.000 / 1.322.000 / 2.980.000 per bulan.
