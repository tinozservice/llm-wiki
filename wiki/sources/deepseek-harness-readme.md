## TL;DR

**DeepSeek Harness (`dsh`)** = agent harness open-source dari DeepSeek AI, arsitektur **everything-is-a-plugin**, ditenagai framework **Cordis** ("A Programming Paradigm for Spatiotemporal Composability"). **Developer preview** — "THERE WILL BE COMPATIBILITY-BREAKING CHANGES". Lisensi **MIT**.

## Key points

- Jalankan: `npx @deepseek-ai/dsh web` → Web UI di `http://127.0.0.1:3080` (dibuka otomatis; `--no-open` untuk server saja; peluncuran SSH hanya mencetak URL); atau dari source (`pnpm install && pnpm run build && pnpm dsh web`).
- Komunitas: GitHub Discussions, topik repo `dsh-plugin` untuk discoverability plugin, **Discord DSH**.
- Sitasi BibTeX tersedia ("DeepSeek Harness: Everything is a Plugin", 2026).
