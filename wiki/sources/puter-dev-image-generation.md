# Puter developer — Image Generation API

- **Sumber**: Puter developer — halaman produk *Image Generation*
- **Penulis**: Puter Technologies Inc.
- **URL**: <https://developer.puter.com/image-generation/>
- **Tanggal publikasi**: tidak dicantumkan; klip dibuat 2026-10-07
- **Berkas mentah**: `raw/2026/oktober/07/puter developer. Image Generation API.md`

## TL;DR

Halaman produk image generation: **40+ model** gambar AI (Nano Banana, GPT Image, FLUX, …) lewat satu API `puter.ai.txt2img()` — tanpa key/server; ganti model cukup satu parameter; user-pays.

## Key points

- "Switch models by changing one parameter", "Always access the latest models", "No vendor lock-in".
- Contoh model di dokumen: `gpt-image-1.5` (GPT-Image) dan `gemini-3-pro-image` (Nano Banana).
- Test tanpa kredit: `testMode` (lihat [docs AI](puter-docs-ai.md)).
- Use case: design tool, platform konten, chatbot dengan output visual, generator aset game, tool sosial media.

## Notable quotes

> "Access Nano Banana, GPT Image, FLUX, and more through a single API."

## What this changes

- Melengkapi [docs AI](puter-docs-ai.md)/[AI Gateway](puter-ai-gateway.md): nama model gambar konkret (`gpt-image-1.5`, `gemini-3-pro-image`) — bisa dibandingkan nanti dengan katalog model gambar di layanan lain (mis. Tokenra `gpt-image-2.5-flare`).
- Tidak ada kontradiksi.
