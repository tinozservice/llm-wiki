# Manus — Privacy Policy

## TL;DR

Kebijakan privasi seluruh layanan Manus (agen AI, aplikasi/extension, Spaces, API, Team Plan): **Butterfly Effect Pte. Ltd.** adalah controller, sedangkan untuk data Space End Users / API Customer / Team Plan, Manus berperan sebagai **processor** atas instruksi pemilik. Mencakup kategori data (termasuk Financial/Health Data bila pengguna memasukkannya, kredensial pihak ketiga, data sandbox & Browser Operator), tujuan penggunaan (memori persisten, Wide Research), berbagi, retensi, transfer internasional, dan addendum per yurisdiksi. Layanan untuk **18+**.

## Key points

- **Kategori data khas**: Inputs/prompts & user-generated content + metadata; **Financial Data & Health Data** hanya sejauh dipilih/diupload pengguna; **Third-Party Credentials** disimpan untuk mengautentikasi fitur terkait; **Derived data** dari fitur avatar/voice (dapat dianggap biometric data di sebagian yurisdiksi AS); **Sandbox environment data** (file, shell command + output, kode, log eksekusi); **Browser Operator / "My Browser" Connector** (konten halaman yang dibaca, aksi klik/form/navigasi, konteks sesi login — dikirim ke server Manus; dapat dicabut dengan menonaktifkan Connector/uninstall extension).
- **Penggunaan**: mengirim input ke third-party AI providers; **memori persisten** ("later tasks and other Agents acting for you"); kolaborasi tim (sync session antar anggota terotorisasi, monitoring usage); Scheduled Tasks & operasi background (log eksekusi disimpan untuk replay/debugging); **Wide Research** (banyak agen paralel, kontrol data sama).
- **Retensi**: menghapus akun → data dihapus dari sistem **≤30 hari** (kecuali kewajiban hukum, sengketa, fraud/abuse, pembukuan); **sandbox** otomatis dihapus: **7 hari** (free) / **21 hari** (paid) sejak aktivitas terakhir; data tim ditentukan Owner/Admin; data End Users disimpan atas instruksi Space Owner/API Customer.
- **Berbagi (yang menonjol)**: **Owner Team Plan dapat mengakses seluruh session data anggota** (task steps & konten, ekspor, monitoring usage; Administrator hanya subset); payment processor (Stripe, RevenueCat); third-party AI providers; afiliasi Butterfly Effect; pembeli aset dalam transaksi korporat.
- **Addendum yurisdiksi**: EU/UK (legal basis per tujuan; representative **EDPO**), California CCPA/CPRA (opt-out targeted ads, GPC), Korea PIPA (PIPO), Jepang APPI, Singapura PDPA (notifikasi breach ke PDPC; transfer dengan perlindungan setara).
- **Anak**: "not intended for use by anyone under 18 years of age".
