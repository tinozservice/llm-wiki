- **Sumber**: openai.com/open-models/

## TL;DR

Model open-weight OpenAI: **gpt-oss** (120B & 20B) — reasoning model untuk desktop/laptop/datacenter; **gpt-oss-safeguard** (120B & 20B) — safety reasoning dengan kebijakan kustom. Lisensi **Apache 2.0**; dirancang untuk task agentik (tool use dalam chain-of-thought, web search, Python); reasoning effort low/medium/high; fine-tuning full-parameter; **full chain-of-thought** untuk debugging.

## Key points

- Performa gpt-oss-120b: MMLU 90,0; GPQA Diamond 80,1; HLE 19,0; AIME 2024/2025 96,6/97,9 (20b: 85,3/71,5/17,3/96,0/98,7) — dibanding o3/o4-mini.
- Playground interaktif di browser; feedback via Hugging Face community.
- Konteks wiki: model ini yang dijual di banyak gateway ([Groq](../entities/groq.md), [Cerebras](../entities/cerebras.md), [Novita](../entities/novita.md), [Token Harbor](../entities/token-harbor.md) dll.).
