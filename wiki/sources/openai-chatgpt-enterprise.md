## TL;DR

ChatGPT Enterprise: deploy ChatGPT dengan **ChatGPT Work + Codex**, kontrol enterprise. Data bisnis **tidak dipakai training secara default**; enkripsi, retensi, compliance; admin mengontrol agen/tools/actions; **Compliance API** untuk visibilitas percakapan & aktivitas agen. Statistik pelanggan: 100% active users, 83% WAU, 98% prefer ChatGPT Enterprise, 10× insight R&D, 6× AI fluency.

## Key points

- ChatGPT Work: plan → aksi lintas apps/files → material jadi (spreadsheet, slide, docs, web app), termasuk proyek berjam-jam; "ChatGPT Sites" untuk landing page.
- Codex: agent lintas codebase — paham task → inspeksi → plan → perubahan → tes → PR.
- Dukungan: playbook deployment, analytics workspace, role-based courses, **AI advisors**, support 24/7 SLA + premium opsional.
