# Exabytes

**Exabytes Network Indonesia** adalah penyedia solusi digital Indonesia (klaim **26+ tahun pengalaman**, **160.000+ bisnis**, rating 4,9/9.303 ulasan) yang memposisikan diri "Perusahaan Solusi Digital Berbasis AI Terkemuka di Asia Tenggara". Ekosistemnya mencakup **domain, hosting, VPS, dedicated server, cloud (Vision Cloud), bizapp (Microsoft 365, Google Workspace, Heylink, Lark), commerce, dan AI** — dengan slogan "GROW AI" ([landing](../sources/exabytes-landing.md)). Server utama di **NEX Data Center Jakarta Selatan (Tier-3)**; bersertifikat **ISO 27001:2013 & 9001:2015** ([VPS Linux](../sources/exabytes-vps-linux.md)).

## Yang membedakan

- **Merek "AI Hosting"**: semua lini shared hosting di-branding AI — AI Website Builder, AI Writing Assistant, AI Image Generator, AI Agent ([web hosting murah](../sources/exabytes-web-hosting-murah.md)); ditambah **AI Domain Name Generator** gratis ([generator](../sources/exabytes-ai-domain-generator.md)).
- **VPS aplikasi AI siap pakai**: tiga varian seri NVMe yang sama dengan agent-nya terinstal — **[Hermes Agent](../sources/exabytes-nvme-vps-hermes.md)** (MIT, Nous Research, memori persisten, multi-channel), **[OpenClaw](../sources/exabytes-nvme-vps-openclaw.md)** (platform MIT dari OpenClaw Foundation — eksekusi shell + chat apps), dan **n8n** ([n8n](../sources/exabytes-nvme-vps-n8n.md)). Beda dari Hostinger (katalog app) — di sini agent jadi identitas paket.
- **Reseller bizapp**: Microsoft 365 (data backup di Kuala Lumpur, PCI DSS), Google Workspace (dengan Gemini; mitra lokal), Heylink (link-in-bio), dan Lark (kolaborasi tim) — satu pintu dengan hosting.
- **Kebijakan khas**: gratis domain bersyarat siklus ≥12 bulan (aturan rumit per paket); jaminan uang kembali **100 hari** untuk paket menengah ke atas; backup mingguan (entry) vs harian (menengah); garansi setup dedicated **4 jam**; garansi penggantian hardware dedicated **6 jam**; **80% bandwidth VPS dialokasikan untuk akses lokal Indonesia / 20% internasional** (berlaku di semua lini VPS).
- **Promo aktif saat klip (Okt 2026)**: `10SALE-HOSTING` (diskon 50% hosting, 6–10 Okt) dan `10SALE` (domain .ID Rp120.000 + undian, 10 Okt).

## Kelemahan / catatan kualitas data

> [!warning] Contradiction: klaim uptime tidak konsisten antar halaman — dominan 99,9%, tetapi ada 99,99% (FAQ hosting & WP), 99,8% (Windows hosting), serta 99,5% server/99,9% network (FAQ Windows hosting). Semua materi pemasaran, bukan laporan independen.

- **Teks promosi usang** masih tayang: promo "sampai 31 Desember 2018" di halaman Windows Dedicated; harga OpenClaw FAQ "Rp150.000-an" vs tabel "Rp194.000".
- Staf runtime lama di WP hosting (Node.js 12.4, Python 2.7) meski diposisikan "AI hosting" ([fitur WP](../sources/exabytes-wp-hosting-fitur.md)).
