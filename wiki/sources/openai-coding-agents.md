## TL;DR

**Codex** = coding agent OpenAI di ChatGPT: menyelesaikan PR, refactor, review, automasi "across parallel workflows"; **multi-agent** (banyak agen paralel dengan computer/browser tools untuk verifikasi); **cloud environments** per repo (lanjut saat laptop ditutup); review PR otomatis. Tersedia di **ChatGPT, IDE, terminal** — satu akun ChatGPT. Harga Business: **IDR 337.000/user/bulan** (2+ seat, tahunan).
