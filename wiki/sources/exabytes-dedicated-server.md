## TL;DR

Managed Linux Dedicated Server Exabytes: empat paket dari **Rp1.978.917/bln** (Xeon E3, 16 GB, 2×1 TB RAID1 SATA) hingga **Rp7.918.917/bln** (dual Xeon E5, 64 GB, 4×2 TB RAID10). Garansi setup **4 jam** (jam kerja), server di **NEX Data Center Jakarta Selatan (Tier-3)**, dikelola Plesk Onyx, backup harian **Idera R1Soft 14 hari**, dan garansi penggantian hardware **6 jam**.

## Key points

- Paket (Managed Plan): Economy Rp1.978.917 (Xeon E3, 16 GB, 2×1 TB SATA RAID1); Value Rp3.298.917 (Xeon E3, 32 GB, 2×960 GB SSD RAID1); Deluxe Rp5.278.917 (dual Xeon E5, 64 GB, 2×2 TB SATA); Ultimate Rp7.918.917 (dual Xeon E5, 64 GB, 4×2 TB RAID10).
- Semua paket: unlimited transfer, 2 dedicated IP, 200 Mbps, setup gratis, garansi setup 4 jam, backup harian 14 hari (extendable 60 hari via add-on), SSL/HTTPS gratis, uptime monitoring, support & OS.
- Brand hardware **DELL**; Plesk Onyx 1-click; akses root; dukungan engineer 24 jam (First Level Technical Support: reboot & remote assistance).
- Hardware replacement guarantee **6 jam**; tidak ada kunjungan datacenter oleh pelanggan; migrasi hosting profesional tersedia.
- T&C: harga promo hanya pendaftaran baru (headline Rp1.799.000/bln dengan komit 12 bulan Intel Single Quad Core); pembatalan ≥30 hari sebelumnya.
