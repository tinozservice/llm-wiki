## TL;DR

**ChatGPT Work** = cara mendelegasikan pekerjaan nyata ke ChatGPT: pakai **Chat** untuk tanya-jawab/brainstorm, pakai **Work** saat ingin task dengan hasil jelas (brief, deck, analisis, update berkala, workflow, file yang bisa direview). Work memakai file, plugin, dan tool yang diizinkan untuk mengambil info, membuat file jadi, menjalankan workflow — dengan progres yang bisa diikuti & persetujuan untuk aksi penting.

## Key points

- Desktop app: Work juga bisa memakai file lokal, apps, dan browser (bila tersedia).
- **Local/Cloud**: fitur "Local computer access with Work Cloud" untuk lanjut lintas device; container cloud tidak bisa mengakses file komputer; toggle di composer untuk memilih local/cloud; cloud berguna untuk task terjadwal (riset/cek situs tanpa komputer menyala).
- Contoh use case + prompt: presentasi 8 slide; spreadsheet perbandingan; update berulang terjadwal (`@Slack`, `@Google Drive`).
- Praktik: sebut outcome, sumber/plugin, constraint, definisi "good", dan kapan berhenti untuk review; plugin di **Customize → Plugins**; pilih **GPT-6 Astra** untuk kerja berat, **GPT-6.1 Sol** untuk kompleks yang lebih murah, Luna untuk sederhana; biaya = credits.
- Task bisa dijeda oleh safety review.

## Notable quotes

> "Use Chat when you want an answer… Use ChatGPT Work when you want ChatGPT to complete a task with a clear outcome."
