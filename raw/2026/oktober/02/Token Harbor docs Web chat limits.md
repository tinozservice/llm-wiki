## Web chat limits

What you have left today, and how much storage you are using, is always in the chat under **Settings → Usage**. This page lists the rules behind those numbers.

If you run into a limit, the chat tells you which one at that moment — you never have to check here first.

## Daily limits

A use frees up 24 hours after you make it, not at midnight.

|  | Limit | Notes |
| --- | --- | --- |
| Text on TH-Rudder | Unlimited | Only the speed limits below apply. |
| Voice messages | 100 a day | Recordings turned into text. |
| Pictures | 10 a day | Images generated on a free model. |
| Web searches | 200 a day | On free models, TH-Rudder and passes. Searches paid from your balance aren't counted. After the limit, answers come without a search. |
| Files | 20 a day | PDF, Word, Excel and PowerPoint files made from answers. After the limit, you still get the answer in the chat. |

## Storage

|  | Limit | Notes |
| --- | --- | --- |
| Documents | 10 MB | One allowance for the account, shared by every project. |
| Conversations | 200 | Archived ones count too. At the limit, new chats are declined until you delete some — nothing is deleted for you. |

## Speed

|  | Limit |
| --- | --- |
| Messages | 10 a minute · 200 an hour |
| File uploads | 30 a minute · 200 an hour |
| Voice messages | 20 a minute · 200 an hour |

## Size

|  | Limit | Notes |
| --- | --- | --- |
| Message length | 32,000 characters | A paste over 4,000 characters is attached as a text file. |
| Attachments | Up to 4 per message |  |
| Photo | 10 MB |  |
| Audio | 10 MB |  |
| Video | 100 MB |  |
| Document | 4 MB | PDF or text. |
| Custom instructions | 1,500 characters |  |
| Reply length | About 3,100 words |  |
| What the model sees | About the last 32,000 characters | Of a conversation, including instructions. Older messages, and anything attached to them, drop out first. |

## Keeping

|  | Limit | Notes |
| --- | --- | --- |
| Archiving | After 30 days without a message | Archived chats stay readable under Archived. |
| Shared links | Public for 7 days | After that, the link stops working. The conversation itself is not affected. |
