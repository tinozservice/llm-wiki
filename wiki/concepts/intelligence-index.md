# Intelligence Index (Artificial Analysis)

**Intelligence Index** adalah metrik dari **Artificial Analysis** yang dipakai Token Harbor untuk mengurutkan model lewat kolom **AA Rank** di katalognya (lihat [katalog model](../entities/token-harbor-model-catalog.md)).

## Catatan

- Nilai berkisar 33.7–57.6 pada klip ini; AA Rank tampak mengikuti urutan nilai ini (dengan celah posisi, kemungkinan karena daftar terfilter per kategori).
- Model gratis Token Harbor juga ternilai tinggi (37.9–39.8), di atas Qwen3.8 27B.
- Hubungan Intelligence Index dengan harga tidak linear: model termahal (GPT-6 Astra, Claude Fable 5.1) tidak memuncaki indeks.
