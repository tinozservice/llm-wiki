## Tanya Jawab (FAQ) Node.js hosting

Pertanyaan dan jawaban seputar Node.js hosting.

### Apa itu Managed Node.js Hosting?

Managed Node.js Hosting memudahkan Anda untuk menyebarkan dan menjalankan aplikasi Node.js tanpa harus mengelola server sendiri, sehingga Anda dapat fokus pada pengembangan aplikasi.

### Bisakah saya melakukan deployment dari GitHub, GitLab, atau asisten pengkodean AI saya?

Ya — Anda dapat melakukan deployment dari GitHub atau GitLab, atau langsung dari editor kode AI atau asisten pengkodean AI Anda.

### Apakah fitur keamanan sudah tersedia di Managed Node.js hosting?

Ya, Managed Node.js hosting sudah dilengkapi managed SSL, CDN, WAF, dan proteksi DDoS.

### Untuk siapa Managed Node.js Hosting?

Ini ditujukan untuk para pengembang atau developer yang menginginkan deployment yang mudah dan hosting terkelola tanpa perlu repot memelihara server.
