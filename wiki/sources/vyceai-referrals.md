# VyceAI — Referrals

- **Sumber**: VyceAI dashboard-v2 — tab *Referrals*
- **Penulis**: Vyce AI
- **URL**: <https://vyceai.com/dashboard-v2>
- **Tanggal publikasi**: tidak dicantumkan; klip dibuat 2026-10-07
- **Berkas mentah**: `raw/2026/oktober/07/vyceai Referrals.md`

## TL;DR

Program referral VyceAI: bagikan link/kode — **pengundang dan yang diundang masing-masing dapat $10** kredit saat pendaftaran berhasil. Klip menampilkan contoh akun dengan kode `VYCE_JWZ72P`.

## Key points

- Bonus per referral: **$10** (kedua pihak, "instantly").
- Mekanisme 3 langkah: bagikan link/kode → teman mendaftar memakai link/kode → keduanya dapat $10.
- Link format: `https://vyceai.com/signup?ref=<KODE>`; kode contoh di klip: `VYCE_JWZ72P` (milik akun sumber).
- Melengkapi tabel Free: "Earn credits through referrals" ([pricing](vyceai-pricing-monthly.md)).

## Notable quotes

> "They sign up using your link/code. You both get $10 added to your accounts instantly."

## What this changes

- Pola akuisisi berbasis kredit (bukan diskon harga) — sebanding dengan program reward Token Harbor (first top-up match s.d. $100) tetapi tanpa syarat top-up.
- Catatan: kode referral di klip adalah milik akun sumber; bukan afiliasi wiki.
- Tidak ada kontradiksi.
