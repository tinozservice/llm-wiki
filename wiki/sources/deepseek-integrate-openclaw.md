## TL;DR

[OpenClaw](../entities/openclaw.md) punya **provider DeepSeek** di onboarding: `openclaw onboard --install-daemon` → Setup mode **QuickStart** → Model/auth provider **DeepSeek** → API key → model `deepseek-v4-pro` atau `deepseek-v4-flash`. Dideskripsikan DeepSeek sebagai "open-source personal AI assistant yang terhubung ke chat (Feishu, WeChat) dan dapat diperluas dengan Skills".

## Key points

- Instalasi dari nol: install script OpenClaw (macOS/Linux + Windows PowerShell) → wizard yang sama.
- Mulai: `openclaw dashboard` (Web UI), `openclaw tui`, `openclaw terminal`.
- Konteks wiki: OpenClaw sendiri menyediakan provider OpenCode Zen/Go, OpenRouter, dll. — DeepSeek kini salah satu provider resmi yang didokumentasikan DeepSeek.

## Notable quotes

> "OpenClaw is an open-source personal AI assistant that can connect to popular chat tools like Feishu and WeChat, and can be extended through Skills."
