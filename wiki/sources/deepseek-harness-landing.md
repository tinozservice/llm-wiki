## TL;DR

**DeepSeek Harness (dsh)** — agent harness open-source dari DeepSeek AI, dibangun dengan filosofi **"everything is a plugin"**: instal plugin atau buat lewat chat ("Creator mode") untuk memperluas tools, skills, dan antarmuka. Menangani dokumen, spreadsheet, kode; preview hasil; plugin **Scheduled tasks** untuk otomasi; **trajectory view** untuk inspeksi eksekusi.

## Key points

- Mulai: `npx @deepseek-ai/dsh web` (butuh Node.js) atau clone dari `github.com/deepseek-ai/deepseek-harness`.
- Preview publik ("in preview, with evolving core plugins and APIs") — mengundang komunitas membangun ekosistem plugin DSH.
- Position: infrastruktur open-source, reusable, composable.

## Notable quotes

> "Use DeepSeek Harness to work with documents, analyze spreadsheets, write code, and schedule tasks. Extend its capabilities with composable plugins."
