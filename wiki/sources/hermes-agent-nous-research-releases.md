## TL;DR

Katalog rilis open-source Nous Research (terbaru → lama): **Hermes Agent** (02/25/26 — "autonomous agent yang hidup di server Anda"), **NousCoder-14B** (Jan 2026, post-train Qwen-3-14B untuk competitive programming), **Nomos 1** (30B matematikawan SOTA bersama Hillclimb), **Hermes-4.3-Seed-36B** (Des 2025 — performa setara Hermes-4-70B, dilatih penuh di **jaringan Psyche**), laporan teknis & model Hermes 4 (405B/70B/14B, Llama-3.1), **Psyche Network** (infrastruktur training terbuka), **Atropos** (framework RL environments), DeepHermes-3, dataset Hermes 3, simulator sosial GOD/S8N, paper DeMo.

## Key points

- Tanggal Hermes Agent sebagai rilis: **02/25/26** — "an autonomous agent that lives on your server, remembers what it learns, and gets more capable the longer it runs".
- Jejak riset: reasoning (Hermes 4 hybrid reasoning), efisiensi berpikir ("Measuring Thinking Efficiency"), RL (Atropos), infrastruktur desentralisasi (Psyche), simulasi sosial (GOD, S8N).
- Model dasar: banyak memakai Llama-3.1/3.2 dan Qwen sebagai basis post-training.
