# Hostinger — Supported Frameworks

## TL;DR

Daftar framework Node.js yang didukung Hostinger, dibagi tiga kategori: **frontend statis** (tanpa proses server), **backend** (proses Node panjang), dan **dual-mode** (statis atau SSR sesuai konfigurasi). Auto-detect dari `package.json`; yang di luar daftar memakai **Other** dengan setting manual.

## Key points

- **Frontend (static)**: Angular, Create React App, Gatsby, Parcel, Preact, React, Svelte, Vite, Vue.js.
- **Backend (server)**: Express.js, Fastify, Hono, NestJS, Next.js.
- **Dual-mode**: Astro, Nitro, Nuxt.js, React Router, SvelteKit.
- **Other** (`other`): build script, output directory, entry file manual; output directory diabaikan bila entry file diset.
