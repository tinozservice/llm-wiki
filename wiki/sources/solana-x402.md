## TL;DR

Solana adalah rumah utama **x402**: **500K+ transaksi/minggu, finality 400ms, biaya $0,00025**, **40+ mitra ekosistem**. Statistik halaman: **37 juta+ transaksi x402 di Solana · 20K+ pembeli & penjual · 70% volume bulanan x402 terjadi di Solana**. Ekosistem & toolkit lengkap tersedia — dari facilitator (PayAI), platform API pay-per-use (Corbits), explorer (x402scan), sampai **panduan payment-gate MCP server dengan x402**.

## Key points

- **Ekosistem**: x402.org (Foundation), **Corbits** (monetisasi endpoint via x402), **PayAI** (facilitator Solana + marketplace agen), **x402scan** (explorer open-source), **T54** (trust layer agentic finance), **CDP Wallet** (Coinbase embedded wallet).
- **Toolkit**: x402 Docs (Gitbook), **Faremeter** (framework OSS agentic payments), PayAI, **x402Secure** (SDK lapisan keamanan), **Privy** (wallet), **MCP with x402** (pembayaran untuk MCP server), solana.com templates.
- Angka ringkas di deskripsi halaman: "the payment protocol enabling AI agents to transact autonomously".
