# OpenAI Learn — Pricing (plan & limit)

## TL;DR

**ChatGPT Work & Codex berbagi usage.** Plan: **Free $0**, **Go $8**, **Plus $20**, **Pro dari $100** (tier $100/$200/$500; Ultrafast di $500), **API key** (bayar tarif API; tanpa fitur cloud). Estimasi pesan lokal/5 jam untuk Plus & Standard Business: **Astra 5–45**, **6.1 Sol 15–160**, **GPT-6 Sol 15–150**, **Luna 350–3.000**. Limit 5 jam **tidak berlaku untuk Pro**; Enterprise/Edu flexible pricing tanpa limit tetap (berbasis kredit).

## Key points

- Mode kecepatan & pengali billing (vs Standard): **Fast 2,5×** (subscription) / **2×** (kredit); **Astra Ultrafast 8×/6×**; gambar memakai limit ~3–5× lebih cepat.
- **Voice desktop**: $0.05/menit (budget Codex) atau **1,25 credits/menit** (workspace kredit); GPT-Live mengelola percakapan, model task ditagih terpisah.
- Habis limit: turn aktif tetap diselesaikan (fair use); Plus/Pro bisa beli kredit tambahan; semua user bisa jalan lokal via API key.
- **Sites** termasuk plan eligible (public beta). Usage dashboard: chatgpt.com/codex/settings/usage; `/status` di CLI.
