# Puter developer — Text to Speech API

- **Sumber**: Puter developer — halaman produk *Text to Speech*
- **Penulis**: Puter Technologies Inc.
- **URL**: <https://developer.puter.com/text-to-speech/>
- **Tanggal publikasi**: tidak dicantumkan; klip dibuat 2026-10-07
- **Berkas mentah**: `raw/2026/oktober/07/puter developer. Text to Speech API.md`

## TL;DR

Halaman produk TTS: `puter.ai.txt2speech()` dengan provider **AWS Polly**, **OpenAI TTS**, dan **ElevenLabs** — mesin standard/neural/generative, banyak bahasa; tanpa key/server; user-pays.

## Key points

- Ganti provider/model/cara satu parameter: contoh Polly (`voice: "Joanna"`, `engine: "neural"`), OpenAI (`model: "tts-1-hd"`, `voice: "nova"`), ElevenLabs (`model: "eleven_multilingual_v2"`).
- Bahasa: Inggris, Prancis, Jerman, Spanyol, Italia, dan lainnya.
- Use case: fitur aksesibilitas, e-learning, asisten suara, audiobook, sistem notifikasi, aplikasi belajar bahasa.

## Notable quotes

> "Access AWS Polly, OpenAI TTS, and ElevenLabs through a single unified API."
