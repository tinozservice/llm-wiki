## TL;DR

Platform API OpenAI: "**the all-in-one platform for agents**" — **Build** (Agents SDK + Responses API; voice via **GPT-Live-1**), **Ground** (tools bawaan: web search, file search, remote MCP), **Act** (koneksi aman ke sistem bisnis). Fitur enterprise: **no training on your data**, ZDR by request, BAA (HIPAA), SOC 2 Type 2, data residency, IP allowlist/mTLS, SSO/MFA, enkripsi AES-256/TLS 1.2+.

## Key points

- Webinar 13 Okt: Cognition membawa real-time voice ke Devin dengan GPT-Live-1.
- Harga standar berlaku konteks <272K; ada Batch Processing & data residency.
- Kontrol admin: RBAC tool/model/project, alert billing, usage per project; akses ke ahli OpenAI (account team, solutions architects, kolaborasi riset).
