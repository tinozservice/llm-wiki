# One API for the world's leading AI models — Frontier

- **Sumber**: Token Harbor — daftar model, halaman `/models` (kategori frontier)
- **Penulis**: Token Harbor
- **URL**: <https://tokenharbor.ai/models>
- **Tanggal publikasi**: tidak dicantumkan; klip dibuat 2026-10-01
- **Berkas mentah**: `raw/model frontier token harbor.md`

## TL;DR

Daftar model frontier Token Harbor (klip 2026-10-01) memuat **11 model** dengan **AA Rank** dan **Intelligence Index** dari Artificial Analysis, plus harga per 1M token. Peringkat teratas diisi Claude Opus 5.5 (#1, Intelligence Index 57.6, $4.00·$20.00) sampai GPT-5.6 Terra (#19, 42.1, $2.00·$12.00). Beberapa model punya **varian Fast** yang berharga lebih tinggi. Kolom "Modalities" kosong di klip.

## Key points

- Harga ditulis dalam format **input·output per 1M token** (USD).
- **Varian Fast**: Claude Opus 5.5 ($8.00·$40.00), GPT-6 Astra ($20.00·$100.00), GPT-6.1 Sol ($4.00·$20.00), GLM-5.3 ($2.10·$6.60), Kimi K3 ($4.50·$22.50), GPT-5.6 Terra ($4.00·$24.00).
- Peringkat AA memiliki lompatan (tidak semua posisi muncul) — kemungkinan daftar ini terfilter ke kategori frontier.
- Kimi K3 muncul sebagai `kimi-k3` tanpa nama tampilan pada klip.
- Intelligence Index bersumber dari Artificial Analysis.
