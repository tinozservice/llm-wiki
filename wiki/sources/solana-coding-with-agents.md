# Solana docs — Coding with agents

- **Sumber**: solana.com — dokumentasi *Coding with agents*
- **Penulis**: Solana Foundation
- **URL**: <https://solana.com/docs/intro/coding-with-agents>
- **Tanggal publikasi**: tidak dicantumkan; klip dibuat 2026-10-08
- **Berkas mentah**: `raw/2026/oktober/08/solana. Coding with agents.md`

## TL;DR

Solana menyediakan dua jalur resmi untuk coding agent: **Solana Developer MCP** (`mcp.solana.com`) — server MCP yang membawa pengetahuan Solana terkini ke IDE (Cursor/Windsurf, dll.): dokumentasi Solana, Anchor, **Program Examples**, dan Stack Exchange; dan **Solana skill** resmi (`npx skills add https://github.com/solana-foundation/solana-dev-skill`) plus **Solana Agent Skills library** di solana.com/skills.

## Key points

- Use case MCP: tanya konsep Solana, debug error program, rekomendasi best practice, belajar dari contoh expert, development lebih cepat.
- Setup detail di mcp.solana.com.
- Skill = jalur alternatif bagi yang tidak memakai MCP; library skill komunitas di solana.com/skills.

## Notable quotes

> "The most powerful way to leverage AI for Solana development is through the Solana Developer MCP."
