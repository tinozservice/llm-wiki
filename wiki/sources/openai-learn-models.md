## TL;DR

Panduan model ChatGPT/Work/Codex: **GPT-5.5 pensiun 14 Okt 2026** (semua plan; API tidak terpengaruh) — pengganti: **GPT-6 Sol** (Plus/Pro/Business/Enterprise/Edu) atau **GPT-6 Luna** (Free/Go). Rekomendasi: **GPT-6.1 Sol** untuk coding/agentik kompleks, **Luna** untuk task fokus berulang; **Ultra mode** memakai subagent untuk task besar. GPT-6.1 Sol/Sol/Luna tersedia di **Work & Codex, bukan di Chat**.

## Key points

- Pemilih model + reasoning control di bawah composer; effort tinggi = lebih lambat & lebih banyak token.
- Astra = model paling capable (code, apps, research); 6.1 Sol = near-Astra lebih murah; Luna = paling efisien.
- Ketersediaan tergantung rollout/sign-in/client; **Astra Ultrafast** untuk Pro $500 & Enterprise/Edu tertentu.
