## Apa itu VPS?

VPS (Virtual Private Server) adalah server virtual yang dibuat dari satu server fisik menggunakan teknologi virtualisasi seperti KVM, di mana setiap VPS mendapat alokasi CPU, RAM, dan storage yang terisolasi serta akses root penuh. Anda bisa memilih sistem operasi (Linux atau Windows) dan menjalankan aplikasi apa saja - dari WordPress, Node.js, Python, Laravel, sampai game server.

Berbeda dengan shared hosting yang membagi satu server untuk ratusan pengguna, VPS memberikan resource yang dijamin tersedia untuk Anda - tidak terpengaruh oleh trafik atau kesalahan pengguna lain. Ini menjadikan VPS pilihan tepat untuk website berkembang, toko online, aplikasi custom, dan tim development yang butuh kontrol penuh atas server.

Isolated Resources

Resource tidak dibagi - bebas dari noisy neighbor effect.

Full Root Access

Install OS dan aplikasi sesuai kebutuhan Anda.

Upgrade Fleksibel

Tambah CPU, RAM, atau storage kapan saja secara pro-rata.

Full Virtualization

Berbasis KVM - setiap VPS punya kernel terpisah.

## Pertanyaan yang Sering Diajukan

Temukan jawaban cepat untuk pertanyaan umum mengenai layanan VPS kami.

Apa perbedaan VPS dan shared hosting?

Shared hosting berbagi resource server (CPU, RAM, storage) dengan pengguna lain, sehingga performa bisa fluktuatif. VPS memberikan resource yang dialokasikan khusus untuk Anda, sehingga performa tetap stabil meskipun ada lonjakan trafik. VPS juga memberikan akses root penuh untuk kustomisasi server.

Apakah VPS cocok untuk pemula?

Ya, terutama dengan opsi managed service atau cPanel. Rumahweb menyediakan cPanel Solo gratis untuk paket M ke atas, sehingga Anda bisa mengelola VPS semudah shared hosting. Untuk yang membutuhkan bantuan lebih, tersedia layanan Semi Managed dan Managed.

Berapa spesifikasi VPS minimum untuk menjalankan WordPress?

Untuk WordPress dengan trafik rendah-menengah (hingga 10.000 pengunjung/bulan), paket 1 Core dengan 1GB RAM sudah memadai. Untuk WooCommerce atau WordPress dengan plugin berat, direkomendasikan minimal 2 Core dengan 2-4GB RAM.

Apa keuntungan memilih VPS dengan lokasi server di Indonesia?

Server di Indonesia memberikan latency rendah untuk pengunjung lokal - TTFB lebih cepat, yang menjadi sinyal positif untuk Core Web Vitals (faktor ranking Google). Untuk geo-targeting eksplisit di SERP Indonesia, kombinasikan dengan domain.id atau setting International Targeting di Search Console. Selain itu, data tetap berada di yurisdiksi Indonesia sesuai UU PDP.

Apa itu availability zone dan mengapa penting?

Availability Zone (AZ) adalah lokasi datacenter yang independen secara fisik, dengan power, cooling, dan network yang terpisah - dirancang agar kegagalan di satu zone tidak mempengaruhi zone lain. Rumahweb menyediakan 2 AZ: Zone A di datacenter TechnoVillage (Tier 3) dan Zone B di datacenter DCI (Tier 4), berjarak sekitar 60 km untuk menghindari korelasi gangguan regional seperti bencana alam atau pemadaman listrik area.

Berapa lama VPS diaktifkan setelah pemesanan?

VPS diaktifkan secara instan setelah pembayaran diterima. Untuk pembayaran via transfer bank, aktivasi dilakukan setelah pembayaran terverifikasi oleh sistem.

Apakah Rumahweb membantu mengelola VPS?

Secara default unmanaged: Rumahweb memastikan server tetap menyala dan berjalan normal, sementara isi dan konfigurasinya Anda kelola sendiri. Jika berlangganan cPanel, Anda otomatis mendapat Semi Managed tanpa biaya tambahan. Untuk cakupan bantuan yang lebih luas, tersedia [paket Managed Service](https://www.rumahweb.com/vps-murah/Managed-Service.pdf) seharga Rp 250.000 per bulan di luar lisensi cPanel.

Apakah paket VPS bisa di-upgrade?

Ya. Anda bisa upgrade paket VPS kapan saja, cukup membayar selisih biaya secara pro-rata. Upgrade berlaku langsung tanpa perlu migrasi data.

Apakah paket VPS bisa di-downgrade?

Downgrade tidak tersedia secara langsung. Jika Anda membutuhkan paket yang lebih kecil, perlu membuat VPS baru dan memindahkan data secara manual. Tim Rumahweb tidak menyediakan bantuan pemindahan data untuk proses downgrade.

Apakah tersedia control panel untuk VPS?

VPS tidak dilengkapi control panel secara default. Anda bisa menambahkan cPanel atau Plesk melalui Rumahweb. cPanel Solo (1 akun) tersedia gratis untuk paket M ke atas.

Apakah Rumahweb bisa membantu migrasi data ke VPS?

Ya, dengan ketentuan berikut: migrasi hanya dilayani jika hosting asal dan VPS tujuan sama-sama menggunakan cPanel (mekanisme account-to-account). Untuk migrasi dari provider lain, gratis hingga 5 akun cPanel per bulan. Migrasi dari sesama layanan Rumahweb ke VPS yang lebih tinggi, gratis 1 akun per bulan. Di luar kuota tersebut, dikenakan biaya Rp 50.000 per akun cPanel.

Apa yang terjadi jika VPS melewati jatuh tempo pembayaran?

VPS akan disuspend pada hari jatuh tempo tagihan. Dalam status suspend, VPS bisa diaktifkan kembali dengan data dan IP yang sama. Setelah 7 hari, VPS akan diterminate dan Rumahweb tidak lagi berkewajiban menyimpan backup data.

Apakah VPS yang sudah diterminate bisa diaktifkan kembali?

Bisa, selama backup data masih tersimpan di Rumahweb. Proses reaktivasi dengan restore data dikenakan biaya Rp 50.000 di luar biaya berlangganan VPS baru. Perlu diperhatikan: IP address VPS akan berubah menjadi IP baru setelah proses reaktivasi.

Bagaimana proses reaktivasi VPS yang sudah diterminate?

Hubungi Departemen Sales Rumahweb untuk mengecek ketersediaan data backup. Jika data masih tersedia, tim akan menerbitkan invoice yang harus dibayar pada hari yang sama. Setelah pembayaran dikonfirmasi, VPS akan diaktifkan kembali dengan IP baru.

Bagaimana jika ingin reaktivasi VPS tanpa restore data?

Hubungi Departemen Sales Rumahweb untuk menerbitkan invoice VPS baru. Setelah pembayaran dikonfirmasi, VPS akan diaktifkan dengan fresh install - tanpa data sebelumnya, dengan IP baru.

Apakah VPS KVM bisa diinstall aplikasi apapun?

Ya, selama aplikasi kompatibel dengan hardware dan OS yang digunakan, serta tidak berpotensi membebani network secara berlebihan. Rumahweb secara spesifik melarang penggunaan VPS untuk mining crypto dan aplikasi TeamTalk.

Perpindahan antar zone tidak tersedia. Jika membutuhkan VPS di zone lain, Anda perlu memesan VPS baru di zone tujuan dan memindahkan datanya secara mandiri, misalnya lewat backup-restore.

Apa perbedaan datacenter Tier 3 dan Tier 4?

Tier menunjukkan jaminan keandalan aspek mekanikal (suhu, kelembaban) dan elektrikal (kelistrikan) sebuah datacenter, bukan uptime layanan secara keseluruhan. Tier 3 menjamin keandalan kedua aspek tersebut 99,982% (maksimal sekitar 1,6 jam gangguan per tahun), sedangkan Tier 4 menjamin 99,995% (maksimal sekitar 30 menit per tahun). Zone A Rumahweb berada di datacenter Tier 3, Zone B di Tier 4.

Apakah VPS di-backup, dan bisakah saya membackup sendiri?

Anda bisa melakukan backup dan restore VPS secara mandiri kapan saja, dan panduannya tersedia di Journal Rumahweb. Rumahweb juga menjalankan backup internal dua kali seminggu, tapi backup ini hanya digunakan untuk pemulihan saat terjadi gangguan hardware dan tidak bisa diakses pelanggan. Untuk keamanan data harian, tetap lakukan backup mandiri secara rutin.

Apakah VPS bisa digunakan untuk mengirim dan menerima email?

Secara default, port 25 pada VPS ditutup untuk mencegah penyalahgunaan spam, sehingga pengiriman email tidak bisa langsung dilakukan. Jika VPS Anda memang digunakan untuk email, sampaikan permintaan whitelist ke teknis@rumahweb.com. Tim Rumahweb akan melakukan verifikasi terlebih dahulu sebelum membuka akses port 25 untuk IP VPS Anda.

Saya memesan VPS beserta lisensi cPanel. Bagaimana proses instalasinya?

Anda bisa menginstall cPanel sendiri mengikuti panduan di Journal Rumahweb, atau meminta bantuan tim teknis dengan mengirim email ke teknis@rumahweb.com.

Apakah ada pengembalian dana jika saya membatalkan VPS?

VPS yang sudah aktif tidak dapat dibatalkan sehingga tidak ada pengembalian dana (refund). Karena itu, pastikan paket, zone, dan sistem operasi yang Anda pilih sudah sesuai sebelum memesan.
