## TL;DR

**Reasonix** — coding agent terminal "DeepSeek-native" (cache-first loop, MCP-native): cukup `npx reasonix code` (tanpa instal global); wizard pertama meminta API key (disimpan ke `~/.reasonix/config.json`). Default **DeepSeek-V4-Flash** untuk iterasi hemat; `/pro` untuk V4-Pro sekali turn, `/preset max` untuk seluruh sesi.

## Key points

- Prasyarat: Node 20.10+; Git for Windows.
- Slash command: `/pro`, `/preset max`, `/help`.
