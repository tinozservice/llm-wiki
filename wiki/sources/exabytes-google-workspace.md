# Exabytes — Google Workspace

- **Sumber**: Halaman produk Google Workspace Exabytes
- **Penulis**: aji maundri / Exabytes Network Indonesia
- **URL**: <https://www.exabytes.co.id/google-workspace>
- **Tanggal publikasi**: 2026-10-06; klip dibuat 2026-10-08
- **Berkas mentah**: `raw/2026/oktober/08/Exabytes. Google Workspace Gratis Backup Data Diskon 50%.md`

## TL;DR

Exabytes sebagai mitra Google menjual **Google Workspace** dengan diskon: **Business Starter Rp59.900/akun/bln** (hemat 46%, 20 akun pertama), **Standard Rp149.900** (hemat 34%), **Plus Rp359.900** — semuanya kini **termasuk Gemini** (asisten AI di Gmail/Docs/Meet). Dukungan lokal 24/7, penagihan gabungan, dan pengelolaan langsung dari Exabytes; maksimal 300 akun per paket.

## Key points

- Paket: Starter (30 GB pooled, 100 partisipan Meet) / Standard (2 TB pooled, shared drive, 150 partisipan + recording, riset AI) / Plus (5 TB pooled, 500 partisipan + attendance, Vault).
- Aplikasi: Gmail (email bisnis + anti-phishing/Safe Links), Calendar, Meet, Docs/Sheets/Slides, Drive, Chat, Admin, **Gemini** (side panel, Gems, Gemini Advanced).
- Diskon 50% pembelian pertama + diskon per akun (20 akun pertama); gratis domain; mendukung hingga 300 pengguna (lebih → hubungi sales).
- Penyimpanan **pooled** (dibagi ke seluruh organisasi); file yang dibagikan ke user tidak mengurangi kuota penerima; pintasan/histori versi tidak dihitung.
- Beli lewat partner vs langsung Google: fitur sama, tapi partner memberi **support lokal 24/7** + penagihan bulanan gabungan + admin dari Exabytes.
- Transfer dari Workspace lama: butuh token, diurus tim Exabytes.
- T&C: harga berlaku pembelian awal; diskon dihitung USD (fluktuasi Rupiah); belum termasuk PPN; **tanpa refund**; paket tahunan tidak bisa downgrade; migrasi email Rp1,6 jt/10 mailbox (sama dengan Microsoft 365).
