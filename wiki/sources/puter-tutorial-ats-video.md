## TL;DR

Kursus video membangun **AI Resume Analyzer / ATS** dengan React + React Router + **Puter.js**: buat lowongan, upload resume kandidat, dan pakai AI untuk menilai kecocokan resume–lowongan (skor ATS + feedback). Semua fitur cloud/AI langsung dari frontend, tanpa backend, dan deploy dengan biaya infrastruktur $0 (user-pays).

## Key points

- **Susunan bab** (dari timestamp): Introduction → Project Setup → Homepage/Navbar/Resume Card → Authentication & Introduction to Puter API → Upload Form & File Uploader → **PDF–Image Conversion & AI Feedback** → Resume Feedback Page → Resume Feedback Components → Fetch Real Data di Homepage → Wipe App Data → **Deployment with Puter**.
- Fitur yang dijanjikan di intro: upload resume & lowongan via file storage; analisis instan dengan model gratis ("free GPT, Claude, and even Grok"); **skor ATS real-time + feedback kustom**; UI responsif; deploy tanpa biaya apa pun berapa pun user-nya.
- Rangkaian teknologi memakai cloud + AI Puter.js (storage, AI, database) "no backend, no setup".
- Materi pendukung (link di deskripsi video, tidak di-ingest): free video kit (code/assets), course JSM, dsb.
