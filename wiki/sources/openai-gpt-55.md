## TL;DR

Post peluncuran **GPT-5.5** ("a new class of intelligence for real work"): kuat di agentic coding, computer use, knowledge work, riset ilmiah awal; latensi per-token setara GPT-5.4 dengan intelligence lebih tinggi; lebih hemat token di task Codex. Tersedia di ChatGPT & Codex (Plus/Pro/Business/Enterprise; Pro untuk Pro/Business/Enterprise); API menyusul saat itu. **Catatan wiki**: GPT-5.5 dijadwalkan pensiun dari ChatGPT/Work/Codex pada **14 Okt 2026**.

## Key points

- Benchmark: Terminal-Bench 2.0 **82,7%**, Expert-SWE 73,1%, GDPval 84,9%, OSWorld-Verified 78,7%, BrowseComp 84,4% (Pro 90,1%), FrontierMath T4 35,4% (Pro 39,6%), CyberGym 81,8%.
- Studi internal: >85% karyawan OpenAI memakai Codex mingguan; Finance review 24.771 K-1 (71.637 halaman) — 2 minggu lebih cepat; Comms automasi Slack agent.
- Testimoni: Cursor (Truell), NVIDIA (Boitano — "GB200 NVL72"), Every, MagicPath; contoh proof Ramsey numbers dengan harness kustom.
- Safeguards terkuat saat rilis; ~200 mitra early-access.
