- **Sumber**: Token Harbor — halaman model, `/models?category=rudder`

## TL;DR

**TH-Rudder** adalah model Token Harbor dengan status **Unlimited free, Web chat only**. Ia bukan model tunggal dalam arti biasa: "One model for everything" — TH-Rudder membaca tiap pesan dan meneruskannya ke model yang bisa mengerjakannya (jawaban, penulisan, gambar, berkas PDF/Word/Excel/PowerPoint, dan web search bila perlu). Ia **tidak punya nama API**; pengguna API harus memilih model lain. Gambar dan web search memiliki jatah harian.

## Key points

- **Unlimited chat, gratis, tanpa kartu kredit** — tetapi hanya lewat web chat.
- Berfungsi sebagai **router**: pengguna tidak perlu memilih model; pesan diarahkan ke model yang tepat.
- Menangani jawaban/penulisan, gambar, berkas kantor (PDF/Word/Excel/PowerPoint), dan web search.
- **Tidak punya nama API** — di luar jangkauan API.
- **Pictures and web searches have a daily allowance** (besarnya tidak disebut).
- Melengkapi konteks "Rudder" di sumber harga Token Harbor: aplikasi chat di tokenharbor.ai/chat.

## Notable quotes

> "One model for everything. Just say what you need — TH-Rudder reads each message and hands it to a model that can do it: answers, writing, pictures, PDF / Word / Excel / PowerPoint files, and a web search when the question needs one. You never have to pick a model."

> "Unlimited chat, free, no credit card needed. Available in web chat only — it has no API name."
