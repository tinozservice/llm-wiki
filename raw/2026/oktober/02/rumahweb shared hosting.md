## Pertanyaan yang Sering Diajukan

Temukan jawaban cepat untuk pertanyaan umum mengenai layanan hosting murah kami.

Apakah Hosting Murah itu?

Hosting Murah adalah layanan penyimpanan file website, database, juga email agar dapat website diakses melalui internet dengan biaya yang murah. Singkatnya, apabila Anda ingin memiliki website maka Anda membutuhkan web hosting untuk menyimpan file text, gambar, video yang ditampilkan di website agar dapat diakses dari seluruh dunia. Hosting murah sendiri adalah layanan web hosting berbiaya murah yang disediakan oleh Rumahweb.

Apakah gratis domain di paket hosting berlaku selamanya?

Gratis domain berlaku untuk satu tahun pertama, sedangkan untuk perpanjangannya berlaku harga normal. Rumahweb menghadirkan domain gratis dalam paket hosting murah sebagai wujud komitmen kami untuk meminimalkan biaya dari sisi Anda untuk mulai meng-online-kan bisnis dan mulai mendunia.

Paket Unlimited apakah benar-benar unlimited atau ada batasannya?

Kami tidak membatasi kapasitasnya sepanjang digunakan dalam batas normal yang dijelaskan dalam [Acceptable Use Policy (AUP)](https://www.rumahweb.com/acceptable-use-policy-aup/). Saat Anda menggunakan akun hosting di atas Acceptable Use Policy, maka akan ada beberapa konsekuensi seperti tidak dibackupnya file, tidak dapat mengupload file, hingga resiko dihentikannya layanan hosting Anda.

Bagaimana jika saya membutuhkan space yang besar?

Layanan hosting murah dirancang untuk website dengan pemakaian space yang wajar sebagaimana sebuah website perusahaan, sekolah, maupun organisasi. Kami rekomendasikan Anda menggunakan layanan Cloud Hosting atau VPS yang memang resourcenya digaransi (dedicated), serta backupnya juga dijamin.

Apa yang dimaksud dengan Turbo Booster?

Turbo Booster adalah fitur untuk membuat website Anda lebih cepat diakses hingga 32 kali lipat. Fitur ini adalah hasil riset dari team RnD Rumahweb yang menggabungkan kegesitan web server dari Litespeed, multi-layer caching, dan berbagai teknologi lain yang mampu membuat website Anda lebih cepat dibandingkan jika menggunakan standard Apache Web Server seperti yang kebanyakan provider hosting lain. Gunakan setidaknya paket hosting MEDIUM yang sudah dilengkapi dengan fitur Turbo Booster agar website Anda menjadi jauh lebih cepat diakses sehingga membuat ranking SEO menjadi lebih baik dan pengalaman pengunjung menjadi jauh lebih mengesankan.

Apa yang dimaksud Cloud Resource/Cloud Power?

Cloud Resource/Cloud Power yaitu batasan penggunaan resources (CPU, RAM, IO) yang dialokasikan pada tiap-tiap paket hosting. Setiap tinggi paketnya, Cloud Power yang dialokasikan akan semakin besar sehingga mampu melakukan proses yang lebih besar dan lebih banyak lagi yang mana akan dibutuhkan jika melayani lebih banyak pengunjung.

Apakah yang dimaksud 3 website, 6 website, dan unlimited website pada tiap paketnya?

Yang dimaksud dengan jumlah website itu artinya dalam satu hosting dapat digunakan oleh beberapa website, sesuai batasan jumlah website yang tertera pada masing-masing paket tersebut. Untuk menambahkannya dapat dilakukan dengan cara Addon domain di cPanel. Dengan begitu, Anda tidak perlu membeli hosting terpisah untuk masing-masing domain yang dimiliki. Meski demikian memang disarankan untuk memiliki hosting terpisah untuk masing-masing domain agar Cloud Powernya tidak terbagi untuk beberapa domain dan lebih aman karena jika terjadi hacking ke salah satu website tidak akan merembet ke website lain.

Database apa saja yang disediakan di layanan hosting murah di Rumahweb?

Kami menyediakan database MySQL/MariaDB dengan jumlah database unlimited yang dapat dikelola menggunakan PHPMyAdmin di dalam cPanel.

Apakah untuk website buildernya hanya tersedia menggunakan SitePro Website builder saja?

Saat ini memang kami hanya menyediakan Site.Pro untuk website builder. Namun demikian, Anda juga dapat menginstall WordPress sebagai CMS yang paling populer dan menambahkan plugin website builder di dalamnya.

Apakah harga paket sudah termasuk fitur auto backup?

Free backup yang disediakan adalah weekly backup dari server, apabila ingin menggunakan backup harian, maka dapat memesan layanan tambahan [Daily Backup](https://www.rumahweb.com/journal/daily-backup/#Apa_itu_Layanan_Daily_Backup) yang sudah tersedia di Rumahweb. Sebagai informasi, fitur free backup akan dihentikan apabila Anda melanggar AUP. Silahkan simak detail Acceptable Use Policy kami.

Apa fungsi Free SitePro sitebuilder?

SitePro website builder digunakan untuk membuat web dengan mudah, dimana sudah disediakan desain/template dari SitePro. Menggunakan SitePro, Anda tinggal memilih template desain lalu mengubah isinya. Simpel dan mudah.

Apa saja batasan Free SitePro sitebuilder?

Untuk SitePro versi Gratis (SitePro Free Plan) memiliki batasan jumlah halaman yang bisa dibuat yaitu maksimal 3 (tiga) halaman web, template yang terbatas, dan tidak bisa mengubah footer. Apabila Anda ingin fitur yang lebih lengkap, Anda dapat upgrade SitePro menjadi [SitePro Premium](https://www.rumahweb.com/journal/cara-upgrade-paket-sitepro/).
