## TL;DR

Dedicated server DomaiNesia (HPE ProLiant enterprise-class) dengan seri **Neva**: Intel Xeon dan AMD EPYC, harga **Rp4.799.000–13.950.000/bulan**. Varian **Neva Genoa GPU** (AMD EPYC 9124P + **NVIDIA L4**, 128 GB RAM) Rp13.599.000. Proteksi DDoS, resource penuh, support 24/7.
