## TL;DR

Rilis terbesar dalam sejarah OpenClaw (release notes `2026.8.1`): **933 kontributor** (569 first-time), **16.000+ pull request**, ~50% dari seluruh PR yang pernah di-merge. Awalnya hanya ingin menyederhanakan instalasi & membangun ulang browser app sebagai pengalaman kelas satu — berubah menjadi "OpenClaw 2.0" yang menyentuh semua bagian.

## Key points

- Sebelumnya: 106 rilis dalam 230 hari (kebanyakan selang 1–2 hari); rilis ini menahan ship ~7 minggu karena basis & proses tak lagi menampung volume kerja — keduanya dirombak sekaligus.
- Instalasi dipermudah: mulai dari yang sudah ada di komputer (langganan ChatGPT/Claude, API key, model lokal); banyak konfigurasi dipotong/dipindah keluar dari setup awal; sisa setup bisa diselesaikan dengan berbicara ke Claw.
- Browser app dibangun ulang: dibuka langsung ke percakapan; tempat menyelesaikan setup, kembali ke kerja berjalan, atau mengikuti live.
- **Multiplayer**: shared cloud sessions → anggota tim bisa masuk ke pekerjaan live atau hand-off dengan konteks utuh; tim OpenClaw sendiri memakai ini untuk membangun OpenClaw (dashboard "The Daily Claw").
- Narasi adopsi: satu alur berguna (mis. pantau email sekolah → Telegram) → tumbuh lintas aplikasi (iMessage → cari receipt → balas).
