## TL;DR

Cloud hosting DomaiNesia (SSD NVMe, semi-dedicated, managed, integrasi MCP AI). Paket unggulan: **Cirrus 2GB Rp112.500/bln** (2 core, diskon 50%), **Cirrus 4GB Rp210.000** (3 core, diskon 38%), **Cirrus 12GB Rp705.000** (6 core, diskon 38%); tabel perbandingan juga mencakup 8/16/24 GB. Direct Connect 10G ke CDN (Akamai, Cloudflare). Klaim "3× lebih handal" dari web hosting.

## Key points

- Resource Cirrus: 2GB = 2 core/40 GB/EP 200%; 4GB = 3 core/80 GB; 12GB = 6 core/320 GB; (8/16/24 GB: 2–7 core, hingga 125 EP).
- Fitur sama di semua paket: unlimited website/email/database/bandwidth, gratis domain, remote backup, akses SSH, integrasi MCP AI.
- Bahasa: PHP, Node.js (npm/yarn/pm2), Python, Ruby, Go, Rust, Perl, Bash; framework JS (React, Vue, Next, Nuxt) dan Laravel; database MySQL, PostgreSQL, MongoDB, SQLite.
- Performa: Nginx cache, LiteSpeed SAPI, HTTP/3 (QUIC), Brotli, CloudLinux, Cloudflare.
- Keamanan: 2FA, CageFS, Imunify360, MailChannels spam filter, Let's Encrypt SSL, IP firewall.
- Backup: offsite, monthly, weekly, backup & restore wizard.
- Layanan lain: Cloud VPS mulai Rp80.000/bln, SSL, email hosting, WordPress hosting.
