## TL;DR

Profil perusahaan: Nous Research mengklaim menciptakan **Hermes Agent, "the most widely used open source agent harness in the world"**; misi "open access to intelligence". Linimasa pengumuman berisi dua berita besar: **Series B** (dilaporkan WSJ, 7 Okt 2026) dan **Hermes Index** (6 Okt 2026) — indeks benchmark model *di dalam* Hermes Agent.

## Key points

- **Series B (7 Okt 2026)**: "we have raised a Series B **to bring Hermes Agent to new frontiers (and, yes, build a mobile app)**" — investor termasuk **NVIDIA, M12 (Microsoft), Samsung Next, Robot Ventures, USV, Y Combinator, Menlo Ventures** (per WSJ).
- **Hermes Index (6 Okt)**: rata-rata 4 benchmark (**Hermes Bench** baru + Terminal-Bench 4.0, Terminal-Bench-Science, SkillsBench); semua model menjalankan harness yang sama, reasoning "high" bila tersedia; contoh skor (mean score / cost per task): **Claude Opus 5.5 63,31 / $4,99**; GPT-6 Astra 56,25 / $11,61; Sonnet 5.5 53,14 / $2,82; DeepSeek V4.1 Flash 36,91 / $0,26; Ling 3.0 Flash 21,56 / $0,054.
- **Sign in with ChatGPT** (29 Sep): kemitraan dengan OpenAI — login Nous Portal dengan akun ChatGPT untuk memakai plan ChatGPT di Hermes Agent ("full visibility and controls in ChatGPT settings").
- **Web search gratis** (Perplexity Fast Search) untuk semua tier Nous Portal (24 Sep); **Solar Mini 4 gratis** 2 minggu (3B aktif/35B total, 512K context).
- **Bot Screen** (23 Sep): Hermes Desktop streaming layar/bot live — tonton agen bekerja, ambil alih kapan saja.
- Lain-lain: Grok 4.7 promo 50% via Portal; 326 use case pengguna; NousCon 2026 (30 Okt, NYC — sold out); merchandise.
- Program publik: open source movement, research (agents, arsitektur, sintesis data, fine-tuning, reasoning).
