# Exabytes — NVMe VPS with Hermes

- **Sumber**: Halaman produk "NVMe VPS with Hermes" Exabytes

## TL;DR

VPS NVMe Exabytes dengan **Hermes Agent** terinstal — AI agent open-source **lisensi MIT dari Nous Research** dengan **memori persisten** dan kemampuan menyusun skill sendiri, diakses lewat Telegram, Slack, Discord, WhatsApp, Signal, Email, atau CLI ("satu agent, satu memori di semua platform"). Paket sama dengan lini NVMe (M1–M6, **Rp194.000–Rp2.980.000/bln** triennial), semua sudah termasuk Hermes, AlmaLinux + KVM + full root, setup <10 menit.

## Key points

- Poin penting: software Hermes (MIT), harga mulai **Rp253.000/bln (NVMe M1, paket 3 tahun)** — namun tabel paket M1 menampilkan Rp194.000/bln; Data Center Tier-3 Indonesia; AlmaLinux/KVM/full root; setup <10 menit terkonfigurasi.
- Paket NVMe M1–M6: 4–64 GB RAM, 1–16 vCPU, 50–800 GB NVMe, 2–32 TB transfer, 1 IPv4, backup off-server mingguan, 1 snapshot, uptime monitoring; harga Rp194.000 / 328.000 / 659.000 / 1.123.000 / 1.322.000 / 2.980.000 per bulan.
- Nilai jual: **tanpa biaya per-tugas & tanpa batas eksekusi** (self-hosted); data, memori, skill, dan sandbox tetap di server sendiri; akses root, VM Pannel KVM console.
- Model AI: Hermes butuh model provider — pakai **kredit Nous Portal (300+ model)** atau API key sendiri.
- Rekomendasi resource: 4 GB cukup untuk 1 agent ringan; 8–16 GB untuk subagent paralel, sandbox Docker, otomatisasi browser.
- Use case: always-on business briefing, developer automation, research & web monitoring, satu agent di semua channel dengan memori bersama.
- Tabel perbandingan vs asisten SaaS: data di Indonesia, tanpa kuota per pengguna/tugas, memori portabel; biaya tetap mulai Rp253.000/bln.
- S&K: pelanggan bertanggung jawab atas konfigurasi & keamanan Hermes; Exabytes dapat suspend jika ada risiko keamanan/resource berlebihan.
