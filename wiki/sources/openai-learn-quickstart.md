## TL;DR

Mulai ChatGPT (web/desktop; app untuk macOS/Windows/Linux): install → sign in (atau Codex dengan API key) → pilih folder kerja → pilih mode (**Work** untuk deliverable, **Codex** untuk software, **Chat** untuk tanya cepat) → kirim pesan pertama. Untuk developer: Codex CLI/IDE extension; **Codex Cloud environment** reusable dibuat via Work in → Cloud.

## Key points

- Desktop app: projects, file lokal, task panjang, quick chats.
- Codex Cloud: inspeksi repo + siapkan setup sebelum publish; task cloud bisa dilanjutkan dari web/mobile/desktop.

## Notable quotes
