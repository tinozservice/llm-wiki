## TL;DR

[OpenCode](../entities/opencode.md) memakai DeepSeek langsung: jalankan `opencode` → `/connect` → `deepseek` → API key → pilih model. Disarankan OpenCode **≥ v1.18.30**.

## Key points

- Alur: `/connect` → ketik `deepseek` → pilih provider → API key → pilih **DeepSeek-V4-Flash** (di klip; model Pro juga tersedia di platform).
- Konteks wiki: OpenCode Zen/Go sudah menjual DeepSeek V4 (Flash/V4.1/Pro) di katalognya — panduan ini jalur **BYO key** ke API DeepSeek langsung, bukan via katalog Zen.
