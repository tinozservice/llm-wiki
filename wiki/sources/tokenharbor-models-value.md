# One API for the world's leading AI models — Value

- **Sumber**: Token Harbor — daftar model, halaman `/models?category=value`
- **Penulis**: Token Harbor
- **URL**: <https://tokenharbor.ai/models?category=value>
- **Tanggal publikasi**: tidak dicantumkan; klip dibuat 2026-10-01
- **Berkas mentah**: `raw/model value token harbor.md`

## TL;DR

Kategori **value** Token Harbor (klip 2026-10-01) memuat **8 model** dengan harga per 1M token paling murah di katalog: dari MiMo V2.6 Pro (#13, Intelligence Index 46.3, $0.435·$0.87) sampai Qwen3.8 27B (#44, 33.7, $0.35·$2.10). Dua catatan menarik: **GLM 5.3 Flash** dan **GPT-6 Luna** punya varian Fast, dan **DeepSeek V4.1 Flash** punya tarif **off-peak** $0.15·$0.60 pukul 14:00–00:00 UTC (standar $0.3·$1.20).

## Key points

- Kategori value = model berharga rendah dengan Intelligence Index 33.7–46.3.
- **Varian Fast**: GLM 5.3 Flash ($0.37·$1.25 vs $0.15·$0.5) dan GPT-6 Luna ($0.20·$1.00 vs $0.1·$0.5).
- **Off-peak**: DeepSeek V4.1 Flash $0.15·$0.60 pada 14:00–00:00 UTC.
- MiMo V2.6 Flash ($0.14·$0.28) adalah harga per-token terendah di klip ini.
- Qwen3.8 Flash, DeepSeek V4.1 Flash, dan MiMo V2.6 Flash juga muncul sebagai model gratis di kategori free.
